# 多因子模型

**定义**：以「多个选股因子打分合并」为核心的选股范式——可以是几个因子等权排序，也可以是机器学习把一篮子因子融合成单一得分。属策略**结构**（不是单个因子）：它的输入正是 [[小市值因子]] 等各类 selection factor。

## 共性 / 谱系
- **教学/框架类**（49efd264、f9ca1d2e、c18e0923、b0e7b728）：演示因子打分、ML 回归、单因子检验，绩效非重点。
- **价值类**（c748b9d5、796c6f98、5a5ba567）：低估值/红利因子，常配大盘止损或择时，回撤温和。
- **ML 应用类**（3141242e、c658ef98、01d39031）：把多个量价/基本面因子用 KNN/逻辑回归融合为单一打分，是「多因子」的现代形态。

## 观察
- **⚠ 标签与代码不符：「多因子/ML」族里唯一过闸的样本其实不是多因子策略（矛盾只标记，留人裁决）**。`多因子ML` 家族 2026-08-11 补跑归一化后选出的唯一 gate-pass base [[d02cde29_高质量稳定上涨]]（obj 0.4737 / sharpe 3.21），经源码核对是 **ETF 跨资产动量 + 6 只微盘 + 20 只白马的三分仓恒定混合组合**（`STRATEGY_ALLOCATION` 0.40/0.35/0.25），没有因子打分或 ML 模型；而该族其余 19 个真·因子/ML 成员在冻结台上 **0 个过闸**（本页横评 14 个成员亦全 DQ）。含义：读到「多因子/ML」族的家族级 objective 时，**先核对源码结构再采信**——过闸样本很可能是被误分类的非因子策略，而不是因子模型有效的证据。（先例：`a30641fb` 已由本族改判至 [[小市值]]。）溯源 [[多因子ML]] q-4。

- **【全仓库通用 · 读数纪律】JQ payload 里的 `alpha` 含一块随市场翻号的 beta 信用 —— 把它拆开再谈「选股能力」**（study [[红利低频]] baseline / q-1，base [[93379f98_低换手红利策略]]，TRAIN 2022–2023 + 2022/2023/2024 分窗，冻结零滑点 ⚠，⚠ **该家族 7/7 全 DQ、`objective` 不携带信息**）：恒等式 `alpha = (annual − rf) − β·(annual_bm − rf)` 在 rf = **4.000%** 下把 JQ 的 `alpha` 复现到**小数点后 4 位**（rf 已由本家族与 [[三进兵]] 三条独立路径互证），因此 beta 项的贡献**可以精确读出**，恰为 `−β·(annual_bm − rf)`。含义：**在下跌市里，一本低 beta 的账会被「白送」一笔它并非靠选股挣来的 alpha**；反过来在上涨市里同一机制**反号变成扣分**。实测（β≈0.43 的低频红利书）：两年锚点 alpha 28.51% 里 **+9.10pp（31.9%）** 来自 beta 信用；2022 **+11.53pp（38.8%）**；2023 +5.44pp（17.9%）；而 2024（上涨窗）**−7.32pp（−17.1%，是拖累）**，同一本账却在那一年打出**最高的** alpha 35.42%、最高 sharpe 2.310 与 +30.3pp 原始超额。→ **两条可复用纪律**：**(1)** 见到高 `alpha` 先问「这段窗里基准是涨是跌、β 是多少」，把 beta 信用减掉再谈归因；只在下跌窗上测到的 alpha **无法**区分「选股」与「低暴露」。**(2)** 判别办法是**换一个反向 regime 的子窗**（本例即用 2024 上涨窗一次性证伪了「防守型 beta 收割」假设），而**不是**继续在同向窗里加样本。⚠ 附带限定：翻号检验能排除「纯 beta 会计效应」，但它**排不掉风格 regime 混淆**——本例仍无法分开「持久截面选股」与「红利风格三年皆赢」，那需要 style-neutral 对照臂（全可分红宇宙等权 / 分位内随机化排序）。⚠ 本条只讲 `alpha` 的读数算术，绝对水平仍产自零滑点台。溯源 [[红利低频]] q-1。

- **【方法学 · 一条因子选股链可以「按构造」满足 harness §3 的真实性红线，而不是靠过滤器；但判别器是笔数比较，不是 Δ】**（study [[红利低频]] q-4，base [[93379f98_低换手红利策略]]，TRAIN 2022–2023 冻结零滑点 ⚠，⚠ 该家族 7/7 全 DQ、无 Δobjective）：**当选股要求一个已实现的正向基本面事实**（此例 `dy_ttm > 0`，即必须**已实施**现金派息）**并同时惩罚投机性活跃度**（此例 20 日换手率倒数秩），**§3 要排除的垃圾类在结构上就够不着候选表** —— 补上 `is_st` 过滤（单行）后 Δannual **−0.20pp**、Δsharpe **−0.0154**（预注册证伪线 5pp / 0.25，实测各差一个数量级），vol 与 maxDD **各自到小数点后 5 位不变、且最深回撤窗逐日相同**，beta 只动 0.0004。**但真正支撑「按构造合规」的不是这个近零 Δ，而是笔数**：102 → **101** 笔、亏损单钉死在 24、唯一被删的是一笔**盈利单** ⇒ 与「~20 次调仓里大约只有 1 只 ST 名曾进过前 10」相容。**纪律**：近零的 Δ **分不开**「从来没被选中」（按构造、可外推）与「选中了但恰好无害」（侥幸、样本相关）—— 必须并排比笔数 / W-L / turnover 才能定性。**机理上值得记的一点**：`dy = dps/price` 存在**困境膨胀通道**（股价崩塌会机械抬高股息率、把困境股推**上**排名），它与派息实施要求 + 低换手腿的排除力**方向相反**；此例二者**恰好抵消**、残差 ≈ 0，所以「小 Δ」不等于「没有机制在起作用」，写归因时不要把它读成单一机制。⚠ 三条限定：(a) 这是**替换**测试不是边际移除，Δ 回答「结果有多依赖被允许持有禁止名单」，**不是**「该类股贡献了多少收益」；(b) 合规是**隐式**的，任何放松派息 / 换手要求的改动都会**重新打开**该暴露、须重新审计；(c) 一次干净的 ST 审计**只清 ST 这一条轴**（本例的次新 / 涨跌停仍未审计），也不构成对零滑点折价的放行。**这是第二个该形态的家族**（前一个是 [[大小盘轮动]] q-6 的次新轴，见 [[小市值因子]]「审计一条合规缺口时…」条 —— 那里由**基本面数据要求**隐式排掉次新）。溯源 [[红利低频]] q-4。

- **【全仓库通用 · 方法学】两个因子按「秩相加」融合时，选出来的是**第三个集合**、不是两条单因子集合的混合 —— 所以 `vol混合 < min(vol单腿)` 是**交互**的证据，不是分散化的证据**（study [[红利低频]] q-3，base [[93379f98_低换手红利策略]]，TRAIN 2022–2023 冻结零滑点 ⚠，⚠ 该家族 7/7 全 DQ、无 Δobjective）：把 `total_rank = dy_rank + turnover_rank` 拆成两条单腿（**宇宙、持仓数、轮动周期全部受控不变，只换排序键** —— 这是唯一让两臂可比的前提，做单腿隔离时必须先核这一条），实测**混合在每一条测到的轴上严格支配两条单腿**：total / annual / sharpe / alpha / information / 胜率 / P-L 更**高**，vol / beta / 系统性 vol / 特质 vol / maxDD 更**低**（混合 annual **23.41%** / sharpe 1.4555 / vol 0.1334 / maxDD 9.13%；只留红利 **−0.20%** / −0.2013 / 0.2087 / 26.37%；只留低换手 11.95% / 0.5514 / 0.1441 / 11.28%），且**收益强超可加** —— 混合比两腿之和（−0.20 + 11.95 = 11.75%）高约 **11.7pp、近乎翻倍**，风险却低于任一腿。→ **可复用的判别法**：看到「混合的波动低于任一条腿」时，**不要**默认那是分散化。**(1) 结构论证**：rank-sum 后取 top-N 选中的是「**两条轴上都不差**」的名字，与任一单腿的 top-N **本来就不是一个集合**，因此组合层统计量**不受**「两个 sleeve 的加权平均」这条不等式约束；**(2) 经验判别**：检查混合是否在**收益、风险、成交质量三面同时**支配两条腿 —— **同时支配 ⇒ 交互**；**分散化叙事必然拿一面换另一面**（收益向下平均、风险向下超线性）。**(3) 由此得到的归因语言**：赚钱的是**合取**（此例「既已实施现金派息、又被市场冷落」），**不是**任一因子；且**两条腿的角色可以完全不对称** —— 此例风险画像整条记给低换手腿（**判别证据是它的 `max_drawdown_period` 与混合逐日相同**、且**盈利单笔数与混合完全相同**，而红利腿的回撤落在一段完全不同的 9 个月磨损窗），而**「收益来自高股息」被正面证伪**（单腿年化 −0.20%、P/L 0.874 < 1、胜率由 76.5% 塌到 55.1%）。⚠ **两条限定必须随行**：(a) **窗口绑定** —— 这是单一 2022–23 HS300 熊市窗（基准 −30.55%），机制解释（最高息的派息公司是周期性高 beta 价值陷阱，β 0.73，被 `β·bm ≈ −22%` 吃掉）**本身就蕴含牛市窗会不同**；(b) **这是理解不是建议** —— 交互结论**不**说明 50/50 是最优权重，也**不**授权去搜权重。**配套阅读**：一个「全员 DQ」的判决必须先分开「没有 edge」与「有 edge、但绝对波动装不进闸」——见 [[仓位管理]]，此例正属后者（缺口 13.9pp，对照 [[三进兵]] 的 ~24pp + 无 edge）。溯源 [[红利低频]] q-3 / 收口。
