# 止损模块

**定义**：策略的退出/保护机制，即 `factors.风控` 角色的所有具体信号的聚合。任何 `风控` 非「无」的策略都归入此机制页。它是「止损强度 ↔ 回撤」规律的横向观察面。

## 观察
- **联合止损（个股线 + 大盘趋势）回撤最低**：[[aaba7575_国九小市值排除3bug版]]（11.0%）。
- **仅个股止损线**次之；**无止损**回撤最高（[[cad4cc5d_最小市值轮动不择时]] 43.7%，见 [[小市值因子]]）。
- 低开剥头皮族用「破开盘价 + 固定止盈」替代止损线，属日内强制了结，而非持仓止损。
- **低开剥头皮（[[7a1c225f_小市值低开优化]] 基, epoch2 jul12）退出机制调参地图**——Arc 1 穷尽扫描后各退出旋钮均单峰，jul12-005（objective 1.3898）为联合局部最优。⚠ 零滑点高估（极端日内换手），数值仅结构性参考、非可实现净收益：
  - **(i) 跨日个股止损线 = 死代码**：日内强制了结（破开盘价清仓 + +5% 止盈）先于任何跨日止损触发；给基线加 -8% 成本止损线（[[jul12-002]]）TRAIN objective 与基线**逐位相同** 1.3738，止损几乎从不触发。→ 「止损强度 ↔ 回撤」规律不迁移到日内 flat scalp 范式。
  - **(ii) 破开盘价 EOD 同日清仓 = 承重（load-bearing）**：把「盘中<今开即清」放松成 +1% 带（[[jul12-010]]）objective 从 1.39 **崩到 0.91**（年化 −46pp、回撤 +1.7pp）——放松容忍度会把已失败的日内反转留到收盘，尾部亏损簇集。此离散开关是本范式的核心保护，不可松。
  - **(iii) 固定止盈 = 对称调优峰值 @+5%**（回撤恰在此最小）：+4%（[[jul12-011]]）年化 +0.6pp 但回撤 +2.4pp——更快资金回收→换手 churn 抬回撤（obj 1.3719）；+6%（[[jul12-012]]）年化 −2.8pp、回撤 +0.8pp（obj 1.3540）。两侧都劣于 +5%，止盈线是**双向单峰**旋钮，非「越松越好」。
- **持有周期决定跨日止损是否 live**（epoch2 jul12 Arc-2 微盘多日弧，[[arc2-microcap-rotation]]）：个股 **−15% 跨日止损**在**裸微盘周度轮动**（多日持有）上是 **LIVE** 的——保留年化（46%）、降回撤 25.4%→22.0%，objective 微升为该弧最佳（0.2366，[[jul12-015]]）；但只触及 **idiosyncratic 尾部**，压不动系统性微盘 beta，夏普仅 1.65→1.67、离门槛 2.5 仍远。与 **scalp 弧跨日止损死代码**（[[jul12-002]] 逐位相同、从不触发）**对照**：同一 −X% 止损线，在日内 flat 范式是死代码、在多日持有弧是有效尾部保护——**持有周期（是否隔夜留仓）决定其 live/dead**。⚠ 零滑点高估（周度轮动仍高换手）。
- **【全仓库通用 · 执行虚构】在「每天（日线）」频率的回测里，所有 `run_daily` 盘中时点都坍缩成同一根 bar，盘中止损因此变成收盘价止损，且盘中回撤按结构不可见**（study [[多因子ML]] q-audit 源码审计，0 次回测）：`harness/harness.md` §2 冻结频率为**每天**，`utils/strategy-post-backtest.js` 从不覆盖它（JQ 结果行确认「每天」）。日线一天只有一根 bar，于是 `run_daily(f,'9:31')` / `'10:00'` / `'14:25'` / `'14:50'` **全部在同一根 bar 上执行**，`get_current_data().last_price` 与 `position.price` 都解析为**当日收盘**，市价单也按同一收盘价成交。三个后果，对本页所有「盘中止损/日内强制了结」类结论都适用：**(1) 多档盘中止损坍缩成一次收盘检查**——账户**永远不会**被「盘中砸坑、收盘收回」洗出去，而真实实现一定会被洗，故回测里的止损**既少触发又更便宜**；**(2) JQ 按日收盘净值计算最大回撤 → 盘中回撤在结构上不可度量**，任何「maxDD 只有 X%」的说法只描述收盘净值曲线；**(3)** 叠加零滑点，退出成为**理想价成交**，微盘/涨停类标的尤甚。→ **方法学纪律**：在日线台上做止损件消融时，测到的是「**收盘价止损**的贡献」，**不是**作者代码里那套盘中止损的贡献；两者在实盘可以差很多，结论措辞必须带这条限定。这也给本页既有的「日内强制了结 = 承重 / 跨日止损 = 死代码」这类判定加了一条前置检查：**先确认该实验的运行频率**，分钟频与日频下同一段代码根本不是同一个机制。要真正检验盘中规则需**分钟级频率**，那属于新的 harness 纪元（人类决策），跨纪元数字不可并列比较。溯源 [[多因子ML]] q-audit Finding B。
- **【全仓库通用 · 读数陷阱】消融掉「唯一的亏损出口」会把 `win_ratio` / `profit_loss_ratio` 推向荒谬的好看数字——因为未平仓的亏损永远不进入已实现交易统计**（study [[打板短线]] q-2，base [[439385b4_首板高开低开弱转强混合]]，2022 单年，冻结零滑点 ⚠）：该策略的止盈条件带 `last_price > avg_cost`（**只在浮盈时触发**），故跌破 MA5 止损是唯一能了结亏损仓位的规则。把止损注释掉后，stats 读出 **`win_ratio 98.63%`（72 胜 / 1 负）**、**`profit_loss_ratio 4.3e6`**，而同一次回测的**年化 −200.03pp、maxDD +14.32pp（25.10→39.42%）**——亏损全部以**浮亏**滞留在未平仓头寸里，只在净值曲线上现形，从不变成「已实现的负交易」。→ **方法学纪律（适用于任何用 stats payload 做归因的实验）**：`win_ratio` / `profit_loss_ratio` / 平仓笔数都是**已实现交易**口径，**只有在两侧的退出规则都能了结亏损时才可比**；一旦消融动到退出规则本身，必须**先看 `avg_position_days` 与平仓笔数是否突变**（此例 1.51→14.32 天、156→73 笔）再决定这些比率能不能读，否则会得出与事实完全相反的结论（「去掉止损后胜率提升到 98.6%」）。同源提醒：本页「无止损回撤最高」类结论若基于胜率/盈亏比而非净值曲线，须回头核这一条。**次生发现**：因为止损同时是**资金周转闸门**，去掉它使收益与回撤**同向恶化**（换手 0.3061→0.0952，资金被套死无法接新信号）——即在高频接力范式里，止损的第一身份是**周转装置**而非风险削减器（详见 [[打板与涨停]]）。⚠ 成本偏差方向：被零滑点低估成本的是**换手更高的基线**一侧，真实成本下该 Δ 的绝对值只会更小。溯源 [[打板短线]] q-2。
- **【全仓库通用】显式成交价参数（`MarketOrderStyle(...)`）在日线台上被静默丢弃——实测**（study [[打板短线]] q-1）：去掉入场单的价格参数后全部指标**逐位相同**（Δ=0.0000，含成交笔数与回撤窗）。这给上一条「盘中止损=收盘价止损」的执行虚构加了**第二个、实测层面的证据**：不只时点被坍缩，**价格也不由策略指定**。→ 任何靠「在某个价位成交」定义的退出规则（限价止损、跳空保护、破开盘价清仓的成交价），在本台上测到的都不是作者写的那个机制。**范围限定**：只证明参数被忽略，**未**定位台子实际用哪根 bar 价（需 `MarketOrderStyle(0.01)` 探针，未跑）。与 [[多因子ML]] q-audit Finding B 同形态，n=2，记作加强中的形态而非定律。溯源 [[打板短线]] q-1。
- **【全仓库通用 · 归因纪律】一个 risk-off 覆盖件可能是收益发动机而非尾部保险——在把任何「回撤控制」的功劳记给它之前，先看**最深回撤的窗口有没有移动**（study [[大小盘轮动]] q-2，base [[2f5bc859_四择时大小盘风格轮动]]，TRAIN 2022–2023，冻结零滑点 ⚠）：把该基类的日频 **MACD 顶背离 `dapan` 风控**中性化（单行 `top_divergence = False`）后，maxDD **13.52→13.35%（−0.17pt，反而略好）**，且**最深回撤窗两侧完全相同**（2022-02-10→03-15）—— 这套写来躲 2022 年 2–3 月那类杀跌的风控，**在它本该起作用的那一段里从未起过作用**。它实际买到的是 **total +22.11pt / annual +7.13pt / sharpe +0.46 / 胜率 +4.9pt / P-L 5.930 vs 4.770**（并少做 17 笔交易、beta 0.6043 vs 0.6365、vol 0.2146 vs 0.2259）：其「清仓转债」的动作在**交易层面是择时良好的退出**，不是保险。→ **纪律：`ΔmaxDD` 的量级是弱证据，回撤窗的位移才是强证据。** 窗口**不动** ⇒ 该部件在那次 episode 里根本没触发，任何「它压住了回撤」的叙述立即被证伪；窗口**迁移** ⇒ 消融在别处造出了新的 episode，是正面的机理旁证（对照：[[七星高照]] q-3 关掉 1/4 月日历转持后回撤窗从 2023-09 迁到 2022-03-23→04-26，那才是真实的回撤压制器）。两例合起来给出一张判读表：**窗口不动 + ΔmaxDD≈0 = 从未触发；窗口迁移 + ΔmaxDD 显著 = 真实保护**。附带结论：该家族因此**没有任何一个被证实的回撤控制部件**（另一候选「风格投票」在归档 q-1 里也只换回 ~1.2pt）。⚠ 该消融令 sharpe 2.67→2.2092 **破闸**（锚点边际只有 +0.17），gate flip 本身说明这类「风控件」在收益侧的承重程度常被低估；⚠ 成本偏差已定量（两臂换手差 ≈3.6 轮组合 ≈0.7–1.5pt，远小于 22.1pt 效应）；⚠ recovered-result（执行器 slow-skip，结果自服务端回收，非正常完成契约）。溯源 [[大小盘轮动]] q-2。
- **【读数陷阱之二 · 与上一条独立】胜率还会因为「分布形状」骗人：删掉一个候选池后 `win_ratio` 上升、终值却腰斩**（study [[打板短线]] q-4，同 base，2022 单年）：去掉三池混合里的弱转强腿，`win_ratio` **69.87%→71.54%**、`profit_loss_ratio` 2.28→2.05，而**终值 −48.1%**（annual −262.58pp）——该腿只占约 17% 的平仓笔数却承载了大部分右尾。→ 与上一条并读可得一条通用纪律：**任何动到退出规则或候选集的消融，都不要用 `win_ratio` 判方向**——先看 (1) `avg_position_days` 与平仓笔数是否突变（识别口径假象：未平仓亏损不入统计），再看 (2) `profit_loss_ratio` 与终值是否同向（识别分布假象：赢面高但赢得小）。两个陷阱成因不同（口径 vs 形状），但都会让消融后的比率**看起来变好**。⚠ 该 Δ 的量级与「去腿后单票仓位被动变大」混淆（该 base 按当日候选数等分现金），只能读作在此上下文中的贡献。溯源 [[打板短线]] q-4。
- **【全仓库通用 · 归因纪律】一条 risk-off 通路可以「制造」它被记功去防的那段回撤——消融把防御规则**去掉**、回撤反而**下降**且回撤窗**位移**，就是这个签名**（study [[大小盘轮动]] q-7，base [[2f5bc859_四择时大小盘风格轮动]]，TRAIN 2022–2023，冻结零滑点 ⚠）：该基类在四择时投票 1:1 相持且择时一弃权时会落到第 436 行的 `else 'empty'` → 转持 511010 国债ETF（一条 q-analytic 已证「活着」的现金腿）。把它换成 `else s3_signal`（改由择时三裁决、不再转现金）后，maxDD **13.52→12.41%（−1.11pt）**、objective **0.4550→0.4975（+0.0425）**、total **+10.06pt**，而**最深回撤窗从 2022-02-10→03-15 整体位移到 2023-02-13→04-21**。⇒ 基线那段「最坏回撤」**有一部分是这条现金腿自己造的**：平票时甩进国债ETF、随后再入场，这一进一出的 whipsaw 摩擦生成了那个 2022 episode；删掉兜底，该 episode 随之消失，剩下更轻的 2023 段递补为新的最坏。→ **判读表扩成三行**（前两行见本页 [[大小盘轮动]] q-2 那条）：**(a) 窗口不动 + ΔmaxDD≈0 = 该部件从未触发**；**(b) 窗口迁移 + 消融后 maxDD 上升 = 真实保护**（[[七星高照]] q-3）；**(c) 窗口迁移 + 消融后 maxDD 下降 = 该部件在制造 episode，不是在压制它**（本条）。(b) 与 (c) 的**回撤窗都会动**，所以位移本身只说明「该部件确实参与了那段净值轨迹」，**方向必须由 ΔmaxDD 的符号补足** —— 这也正好补上前一条「ΔmaxDD 量级是弱证据、窗口位移才是强证据」的另一半：**两者要合读，单看任一个都会把 (b) 和 (c) 弄反**。**触发频度的读法**：本例平仓 160→**161 笔（+1）**、`avg_position_days` 59.42→**59.4211**（6 位有效数字不变）、turnover +0.6% ⇒ 该通道**罕见且短暂**，却在**收益（−10pt）与回撤（+1.1pt）两个轴上同时为负** —— **「触发次数少」不等于「无害」**，几次时点糟糕的现金出走足以定义整条净值曲线的最坏段。**归因洁净度的前置条件**（本例满足，值得抄）：替换目标 `s3_signal` 恒为 big/small（其 `'empty'` 分支已被独立证明数学不可达），故消融**不引入新的弃权路径**，Δ 可干净读作「现金腿被移除」而非「换了一套投票规则」。⚠ 零滑点偏差在本例**近乎为零**（两臂 turnover 0.037522 vs 0.0373），故该 Δ 的符号与量级都稳；⚠ 单窗单次观测，跨窗普适性未测。溯源 [[大小盘轮动]] q-7。
- **【判读表第四行】回撤窗**易位到一段互不相干的 episode**（既非不动、也非原窗的收缩）⇒ 该部件不是在给原 episode 削尾巴，而是把**整段 episode 压到另一段之下**（study [[ETF动量]] q-3，base [[22152780_七星ETF轮动V1.7.2]]，TRAIN 2022–2023，冻结零滑点 ⚠）：把小市值腿的 1/4 月日历规则**打开**（第 169 行 `g.avoid_trade_april False → True`，1/4 月满额轮进 511880 货币 ETF）后 maxDD **12.7111→8.9743%（−3.7367pt）**，而最深回撤窗从 **2022-03-22→04-28** 整体跳到 **2022-06-28→07-15**。事前预测是「**截断而存活**」——该规则封 4 月不封 3 月，故 3 月起跑的那段应当缩短但仍是最坏段；**该预测被证伪**。⇒ **判读表补成四行**：**(a) 窗不动 + ΔmaxDD≈0 = 从未触发**；**(b) 窗迁移 + 消融后 maxDD 上升 = 真实保护**（[[七星高照]] q-3）；**(c) 窗迁移 + 消融后 maxDD 下降 = 该部件在制造 episode**（[[大小盘轮动]] q-7）；**(d) 窗易位到一段与任何已测部件的窗都不重合的 episode = 原 episode 被整体降级，且新的约束段可能属于更高的组合层级**（本条 —— 新窗与基线窗、与同基类 ETF 腿满仓隔离的窗 2022-03-22→05-13 **双双不重合** ⇒ 它是**混合层面**而非任一单腿的 episode）。**实操含义**：`ΔmaxDD` 的量级配上「窗**缩短** vs 窗**易位**」才能区分「削尾」与「降级」——**只有窗端点仍与原段重叠时，「截断/削尾」这个措辞才成立**；端点完全不重叠时必须改写成「原段被降级、另一段递补」，否则会把机理说反。
- **【全仓库通用 · 方法学】当两个家族基类只差一小撮**可枚举**的开关时，单开关消融就不再是「重复测一遍」，而是一次**定量的跨版本预测**——符号与量级都可以事前预注册并被检验**（study [[ETF动量]] q-3 × [[七星高照]] q-3 配对，同一「三驾马车」血统的 V1.7.2 与 V1.6，TRAIN 2022–2023，冻结零滑点 ⚠）：两者的小市值腿经比对**除两处开关外逐字节相同**（`avoid_trade_april`、`enable_dynamic_position`）。姊妹 V1.6 把 1/4 月日历规则**关掉**测得 **+4.30pt maxDD / −2.99pt annual**；[[ETF动量]] V1.7.2 把同一规则**打开**测得 **−3.74pt maxDD / +2.71pt annual** —— **符号一致，且两条轴的量级差都在 ≈0.6pt 以内**，在同为 **50% 权重稀释**、同一替代标的（511880 货币 ETF）的条件下。⇒ 三条可复用读法：(i) **效应量可迁移** ⇒ 一次测量在血统内可当作**先验**用，后续同类实验应把「姊妹的效应量」写进预注册带（本例正是这么做的，量级预测命中）；(ii) **它同时把版本退步定量分解了** —— V1.6→V1.7.2 的整体退步（obj 0.4814→0.3830 / sharpe 3.17→2.52 / maxDD 8.53→12.71）中**相当大的一份就是这一行代码**，剩余份额只可能落在另一处开关与另一条腿的版本差上，**这是「版本差」从一句话变成一份账的唯一路径**；(iii) **前提条件必须先核**——「只差 N 个开关」得**逐字节比对过**才能这么读，否则整条腿的版本差（如本血统 ETF 腿池 7→38 + 三个新过滤件）会伪装成单点归因。**机理签名也复现了**：两侧都是**删掉的交易里绝大多数是亏损单**（姊妹 15 笔中 14 亏 / 本例 12 笔中 11 亏）而 **turnover 几乎不变** ⇒ **持仓成分变化，不是降杠杆**——这已是第二个家族出现该签名。⚠ **overfit-suspect 随之迁移，不因符号有利而减轻**：两侧的样本内支撑都只有 **n=4** 次日历事件；⚠ 效应量摊在**半权重**腿上，腿级未稀释效应约 2× 属**未测的推断**；⚠ 零滑点方向在本例**已定**（不做该规则的一臂在 1/4 月持**微盘个股**、做的一臂持货币 ETF ⇒ 不做的一臂真实成本更高，测得的改善是**下界**）；⚠ [[ETF动量]] 侧的数字是 **provenance-recovered**（执行器 `slow-skipped`、非 `completed`，经四路来源核验）。溯源 [[ETF动量]] q-3、[[七星高照]] q-3。
- **【全仓库通用 · 方法学纪律，与上面那张判读表配对使用】`ΔmaxDD` **不是可加量、也不可跨权重外推** —— maxDD 是一个 **max 统计量**，一旦某个部件把「当前绑定的那段 episode」压到**另一段它根本没有触及**的 episode 之下，**后续部件（或同一部件的更大剂量）就再也削不动了**（study [[ETF动量]] q-8 / q-9，base [[22152780_七星ETF轮动V1.7.2]]，TRAIN 2022–2023，冻结零滑点 ⚠）：同一条小市值腿在满仓（`[1,0,0,0]`）下，**两个互不相同**的部件分别打开 —— `avoid_trade_april`（日历轮进货币 ETF）测得 maxDD **14.0067→12.12035%**，`enable_dynamic_position`（按 HS300 20 日波动缩放目标名义）测得 **14.0067→12.12131%** —— **两者落在同一个回撤窗（2022-06-28→07-06）、相差仅 0.001pp**。两者各自**独立地**把 Mar–Apr 2022 那段降级到**第三段谁都没碰过**的 episode 之下；**先开哪一个都行，第二个就没有东西可再削**。⇒ 把两者的 ΔmaxDD 相加（−3.77pp）去对照两者都开的实际缺口（−1.40pp）会得到一个**纯属人造**的 +2.38pp「残差」。**同一现象也让「效应 ∝ 权重」失效**：完全相同的 `avoid_trade_april` 开关，在 **50% 权重**上值 **−3.7367pp**，在 **100% 权重**上只值 **−1.8864pp** —— **剂量加倍、测得效应反而减半**，因为它撞上了同一条地板。⇒ **实操规则（成本为零，抄走即可）**：**在把任何 ΔmaxDD 相加、外推或按权重换算之前，先把各臂的 `max_drawdown_period` 端点并排比一遍**；端点**相同**就意味着已经饱和，此时 ΔmaxDD 只反映「离地板还有多远」，**不反映该部件的保护强度**。**与本页判读表的接口**：判读表的 (a)/(b)/(c)/(d) 判的是**单个部件与单段 episode 的关系**，本条判的是**多个部件（或多个剂量）之间**能不能做算术 —— 两者互补，(d)「窗易位到互不相干的 episode」正是本条所说「地板」形成的机制。**推论**：回撤类归因应尽量用**可加量轴**（annual / turnover）做主检验，maxDD 只作方向性弱检验；本例中 annual 轴确实给出了可解释的信号（+7.56pp vs 0.00pp），而 maxDD 轴上连弱检验都不成立。⚠ 本例两臂都跑在**满仓微盘 × 零滑点台**上，绝对水平（221.31% / 194.82%）**绝不可读作可实现**；但三臂 turnover 在 ±3% 内 ⇒ 省略的成本近乎共模，**臂间 Δ 与本条结论不依赖水平的现实性**。⚠ `avoid_trade_april` 侧带 **n=4** 日历触发的 overfit-suspect，`enable_dynamic_position` 侧带 **n≈1 episode-risk**（只在单一高波动区间咬合）—— **两种小样本风险性质不同，不可压成一句**。溯源 [[ETF动量]] q-8、q-9。
- **【与上一条配对 · 升级为定论】那条「maxDD 地板」是结构性的，不是两点巧合：第三条臂落在同一条地板上，三臂彼此在 0.0036pp 内、`max_drawdown_period` 端点逐日相同**（study [[ETF动量]] q-10，同 base，TRAIN 2022-2023 冻结零滑点 ⚠）：单开 A **12.12035%**、单开 B **12.12131%**、**两者同时打开 12.12397%**，窗口一律 **2022-06-28→2022-07-06** —— 这是一段**两个部件都碰不到、同时打开也碰不到**的共同回撤 episode。**三条可复用规则**：**(1) 用 both-ON 臂来判定地板** —— 两条单开关臂同窗只是提示，**第三条（both-ON）仍落在同窗**才把「饱和」坐实；**(2) 相加得到的 ΔmaxDD「交互项」在这种情形下是纯伪影** —— 本例算出 **+1.889pp** 的「正交互」，其全部来源只是**两条单臂各撞地板一次、both-ON 臂只撞一次**的记账重复 ⇒ 一旦端点相同，**maxDD 的可加性记账必须整体停用**，而不是打折使用；**(3) 地板本身升级为最高优先级的研究对象** —— 地板未被解释之前，任何新部件测到的 ΔmaxDD 只反映「离地板还有多远」，**不反映保护强度**，回撤归因因此被卡住。**另一条实操副产品**：同一部件的 ΔmaxDD 会**随权重上升而变小**（半权重 −3.74pp → 满仓 −1.89pp），所以「按权重换算 ΔmaxDD」同样无效。⚠ 该家族的绝对水平是满仓微盘 × 零滑点台，**不可读作可实现**；可信的是同腿臂间的 Δ 与窗口端点。⚠ **月度 / 分段 P&L 归因在本项目的 stats 端点拿不到**（q-10 实测确认）⇒ 想弄清一条地板 episode 里发生了什么，**只能靠新回测的窗口切分**，不能靠对现有 payload 的再解析。溯源 [[ETF动量]] q-10。
- **【全仓库通用 · 方法学纪律，直接修正本页上面那条「只差一小撮可枚举开关」的观察】「两份代码只差 N 处」必须由**按可达性分类的结构 diff**建立，**不能**由参数块扫描建立 —— 同一对文件，参数扫描给出 2 处，逐 `def` 比对给出 5 处**（study [[ETF动量]] `q-analytic` 源码探针，比对对象 = [[ETF动量]] V1.7.2 与 [[七星高照]] V1.6 的小市值腿，**0 次回测**）：此前「除两处开关外逐字节相同」的说法来自对配置参数块的比对，并被当作背景事实用于跨版本归因。把两份文件按 `def` 拆成单元、按名对齐逐一比对，再按 `proportion[k] > 0` 守卫判定每处差异在目标配置下**是否被调度到**，结果是在同一配置下**至少 5 处可达差异**：两处开关 + `run_weekly(strategy_1_buy, 2, "09:45")` vs `"09:40:02"` + **一份只存在于其中一版的止损冷却过滤**（`filter_cooldown_stocks`，另一版连函数都没有、其两个同名参数是**死代码**）+ `bonus_filter` 的 `fq=None` vs `fq="pre"`（喂进决定选股的排序键，仅 5 月分支可达）。⇒ **三条可复用规则**：**(1)** 「差 N 处」是**待检假设**，检法是**逐单元 diff + 可达性分类**，参数扫描只能给下界；**(2)** **逐字节相同的那一半要一起报** —— 本例 24 个函数（选股池底、市值筛、下单/仓位管线）逐字节相同，这才把「不同宇宙 / 不同池」这类竞争解释关掉，把残差压成**路径 / 选择扰动**；**(3)** **门控在评测窗之外的代码要单独标注** —— 本例 `apply_nine_point_audit` 被 `> 2025-01-01` 门控 ⇒ TRAIN/VAL 惰性但 HOLDOUT 分叉，**任何等价性声明都必须写明它只对哪个窗口成立**。溯源 [[ETF动量]] `q-analytic`（配对家族 [[七星高照]]）。
- **【与上一条配对 · 与本页那条「日线 bar 坍缩」的执行虚构互为反面】一处差异可以**既是真实的源码差异、又在评测台上完全惰性** —— 所以源码级 diff 必须先过一遍台子的执行语义，才能拿来排序解释力**（同上，[[ETF动量]] `q-analytic`，0 次回测）：探针把「`strategy_1_buy` 的调度时刻 `09:45` vs `09:40:02`」排在第 1 位（块内其余 11 条调度逐字符相同，它是唯一的调度差异）。但 `harness/harness.md` §2 冻结频率为 **每天**，日线一天只有一根 bar ⇒ 两个时刻**落在同一根 bar 上**，该差异**不可观测**（本页上方两条实测已确立该坍缩：[[打板短线]] q-1 去掉显式成交价参数后**逐位相同**、[[多因子ML]] q-audit Finding B）。⇒ **纪律**：结构 diff 产出的候选清单，排序前必须逐条问「**在冻结台的执行语义下，这处差异有没有可能改变任何一笔成交？**」——**时刻 / 盘中价格 / 盘中触发**这三类在日线台上一律先降权为惰性；反过来，**改变候选集或排序键**的差异（如本例那条冷却过滤与复权口径）才是有解释力的候选。⚠ 惰性判定是**台子属性、不是代码属性**：换成分钟频率台，同一处差异会立刻变成 live。溯源 [[ETF动量]] `q-analytic`。
- **【上两条的实测结案】「止损后冷却」这类部件的效应落在**成分**上、不落在**回撤**上 —— 它删掉的交易可以很多，maxDD 却可以一动不动**（study [[ETF动量]] q-11，关掉 `filter_cooldown_stocks`（止损/卖出后 N 日内不再买回该票），叠在满仓小市值 both-ON 臂上，TRAIN 2022–2023 冻结零滑点 ⚠）：实测 annual **78.50→75.82%（−2.68pp）**、sharpe −0.3108、成交 **142（89W/53L）→135（89W/46L）**，而 maxDD **停在 12.12397%、最深回撤窗仍是 2022-06-28→07-06**（⚠ 只到记录精度，非 bit-identical）。两条可复用的读法：**(1) 冷却过滤在这里不是风控件而是选择件** —— 它不改变回撤路径的深度，只改变**持有的是谁**；因此把「冷却/黑名单」写进风控叙事时，必须由 `max_drawdown_period` 端点验证，不能默认它保护了尾部。**(2) 方向反直觉：删掉这个「再入场抑制器」让交易变**少**了（142→135），而不是变多。**机制是**替代**：被冷却挡住的名字由选股表下一名**回填**，替代者自己后来也要平仓 ⇒ 多出一个回合；删掉过滤，7 个这样的回合消失，**且这 7 笔全部是亏损单、盈利单 89→89 不动**、turnover 同步下降 ⇒ **成分/路径变化，不是降杠杆**（本项目该签名的第 4 次复现，首次以「删部件」的反向形式出现）。⇒ 纪律：**「这个过滤抑制 X」推不出 Δ成交笔数的符号**，先要知道选股表是否回填（详见 [[小市值因子]] 同一条）。**(3) 与本页那条 maxDD 地板纪律合读**：该家族的 12.12% 地板现已绑定**四条臂**（q-8/q-9/q-10/q-11），且**三处已枚举的差异（日历规则、动态仓位、冷却过滤）没有一处碰得到它** ⇒ 地板本身仍是独立的、更高优先级的研究对象。⚠ 满仓微盘 × 零滑点台，绝对水平不可读作可实现；只有同腿臂间 Δ 可信。溯源 [[ETF动量]] q-11。
- **【全仓库通用 · 方法学，与上面那两条「可达性分类的结构 diff」配对使用】一个**精确的 null**（Δ = 0 到全精度、**一笔交易都没有不同**）比一个「小 Δ」**更强也更便宜** —— 它把一个候选**当场关掉**，而不是留下「小但也许是真的」这种含糊**（study [[ETF动量]] q-12，把 `bonus_filter` 的复权口径 `fq=None → "pre"` 对齐到姊妹 [[七星高照]] V1.6，叠在满仓小市值臂上，TRAIN 2022–2023 冻结零滑点 ⚠）：实测 **九条坐标与对照臂逐位相同到七位有效数字**（annual 75.81748 / total 198.15366 / sharpe 2.8824923 / maxDD 12.123967 / 回撤窗端点 / vol 0.2491506 / turnover 0.0754234 / 成交 135 / 盈亏拆分 89W-46L）⇒ 预注册的「近似 null」结局成立，另两种结局被同一次跑**一并排除**。**三条可复用的读法**：**(1) 精确 null 与小 Δ 不是一回事，必须分开记账** —— 「|Δannual| 0.3pp」只能说「在噪声量级内」，仍要留一个悬案；「Δ = 0.000 且成交笔数与盈亏拆分逐位相同」则**证明该部件在本窗内根本没有改变任何一次决策**，候选清单可以**直接划掉一项**。⇒ 判读时应主动去比**全精度 stats payload + 成交笔数/盈亏拆分**，而不是只看四舍五入后的头条轴。**(2) 精确 null 免疫零滑点保留意见** —— 滑点/成本移动的是**水平**，对一个恒为 0 的 Δ 没有作用；因此在零滑点台上，**null 类结论的可信度高于任何非零 Δ 类结论**，这是零滑点台上性价比最高的一类结果。**(3) 但 null 的**范围**必须随行**：本例那处差异只在 `end_date.month in [5]` 分支可达（约 100 次周度调仓里 8–9 次，**small-n**）⇒ 正确措辞是「**在本窗上惰性**」，**不是**「该口径无关紧要」；换个窗口，未被翻转的排序可以立刻翻转。**与本页上面两条的接口**：结构 diff 先按**可达性**把候选列出来并排序（不能用参数扫描），再逐个测；**一个精确的 null 就是把某个候选从清单上永久移除的最干净方式**，而清单被穷尽之后，剩下的残差就该被诚实登记为「**未枚举的开放缺口**」，并改用**探针**（持仓/成交明细）而不是再花一次盲消融。⚠ 本例所在的臂是满仓微盘 × 零滑点台，绝对水平（198.15% / annual 75.82%）**绝不可读作可实现**；但如上，**null 结论本身不依赖水平的现实性**。溯源 [[ETF动量]] q-12（配对家族 [[七星高照]]）。
- **【指数级「整卷跳过」型止损的一次干净标定：它改回撤的**幅度**，但既不改回撤的**时点**、也不改整本账的 `vol`】**（study [[网格]] q-2，base [[32021d45_【网格交易策略-年化30%+】-网格大法好，熊市]]，消融「上证指数 2 日跌幅 > 3% ⇒ 当日整卷不操作」，TRAIN 2022–2023 冻结零滑点 ⚠，⚠ 全窗 DQ ⇒ **不报 Δobjective**）：关掉它 —— annual **33.79→20.42%（−13.37pp）**、sharpe **1.1873→0.6333**、maxDD **19.677→28.99%（+9.31pp）**、turnover **0.010291→0.006513（−36.7%）**、成交 118（83W/35L）→83（64W/19L）、P/L 5.050→2.811。三条可复用的读法：**(1) 它是实质贡献者、但不是收益发动机** —— 供给约 13pp 年化与约 9pp 回撤压制，而该家族的过闸缺口是 **≈35.6pp** ⇒ **「这个部件很重要」与「这个部件能救这个策略」是两句话**，量级要和缺口并排写。**(2) 最有信息量的一项是那个**没有**变的量：去掉它之后最深回撤的窗口端点与基线**逐字节相同**（2022-02-10→2022-04-28）** ⇒ 它**连「最差回撤发生在什么时候」都没有改变**，只削掉了幅度。→ 与本页那条「冷却过滤动成分不动回撤」构成互补的一对：**判定一个风控件到底动了什么，必须同时看 `maxDD` 的**值**与 `max_drawdown_period` 的**端点**，两者的组合有四种，头条轴只能看见一种。** **(3) 它也不是波动源**：Δvol 仅 **+0.91pp**（0.261358→0.270467），且点名的**反向信息情形（去掉止损后 vol 反而下降，即该止损自身在制造波动）未出现** ⇒ 在这本账上，`vol` 由**结构**而非由风控开关决定（见 [[仓位管理]]「结构性波动」条）。⚠ 预注册的三条量级杆（annual ≤−20pp / maxDD ≥+10pp / vol ≥+3pp）**一条都没够着** —— 方向全对、量级全部高估，**如实记录**：这类「整卷跳过」开关在直觉上容易被高估。⚠ 零滑点折价在本家族已定尺寸为 0.6–1.9pp/年（turnover 0.0065–0.0186），对上述 Δ 无关紧要。溯源 [[网格]] q-2。
