# 仓位管理

**定义**：策略的资金配置与持仓数机制，即 `factors.仓位` 角色（等权 / 动态持仓数 / 满仓单标的 / 流动性配权 / 预留资金）的聚合。此页作为「持仓数 / 配权方式 ↔ 收益·回撤」的横向观察面。受控概念登记见 `docs/wiki-schema.md` §2（仓位管理 · 机制）。

## 仓位变体一览
| 仓位类型 | 做法 | 代表策略 |
|----------|------|----------|
| 等权 + 固定持仓数 | 目标持仓数 N，`available_cash/len` 等额分配 | [[7a1c225f_小市值低开优化]]（target_count=5，本纪元实验基线 jul12-000） |
| 动态持仓数（MA 偏离） | 按指数 MA10 偏离弱市多持/强市少持（3~6 档） | 小市值 MA10 偏离族（见 [[择时-均线]]） |
| 预留资金 | 只用总资金的一部分（如 50%）滚动 | [[7a1c225f_小市值低开优化]]（预留 50%） |

## 观察
- **低开小市值剥头皮基上，目标持仓数敏感度单峰、内点在 6**：[[jul12-005]] 实验对基线 [[7a1c225f_小市值低开优化]]（target_count=5）做 count 扫描（idea-4），TRAIN objective —— count=5 基线 1.3738 · **count=6 峰值 1.3898** · count=8 1.3229 · count=10 1.3543。呈单峰内点峰值：edge 集中在最好的少数几笔剥头皮，持仓数超过峰值即被边际弱标的稀释、低于峰值则集中度过高。count=6 为本纪元唯一相对基线正向改进者，定稿 VAL 1.3231 过门槛且与 TRAIN 同向（`confirmed`）。⚠ 该基为高换手日内剥头皮，零滑点下 objective 偏高估；峰值增益仅 +0.016，可能含样本内噪声。

- **分散化（增持仓数）是低开剥头皮基上唯一有效的降回撤杠杆**（epoch2 jul12, Arc 1 收敛）：count 5/6/8/10 扫描（[[jul12-004]]/[[jul12-005]]/[[jul12-006]]）内点峰值 @6，靠**增分散**平滑联合回撤且不剥离 junk-tail alpha；而**质量过滤**（国九条，[[jul12-003]]）反而把回撤从 11.1% 抬到 23.3%（缩池→更集中）。即在此基上「多持一只」优于「筛掉差的一只」——分散是收益-中性的抗回撤手段，过滤是收益-破坏的。⚠ 零滑点高估，峰值增益仅 +0.016，可能含样本内噪声。

- **恒定混合（constant-mix）权重消融自带「闲置现金」混淆：Δ 里混着一笔现金拖累与一份机械降波**（[[多因子ML]] q-1/q-2，TRAIN 2022-2023 冻结零滑点 ⚠）：各仓按 `total_value × 权重` 定仓时，把某仓权重置 0 后那笔资金**不会分给其余仓**，而是空闲吃 0 收益。于是 (a) Δannual = 该仓边际损益 **+** 这笔资金失去的复利（该仓自身的边际 P&L 一定**小于**测到的 Δ，差额未知）；(b) maxDD 会**机械下降**，经验量级约 **−0.04pp per idle weight-point**（实测 35 权重点 → −1.42pp、40 权重点 → −1.85pp）；(c) sharpe 会被现金稀释**人为抬高**，所以「消融后 sharpe 没跌破门槛」不能当作该仓无关紧要的证据。→ 结论措辞的红线：只能说「该仓位**在其固定混合权重下对组合的贡献**」，不能说「该仓策略自身的收益能力」。若要去掉混淆，需把释放的权重按比例回填给其余仓（那是另一个实验，且改动不止一处）。溯源 [[多因子ML]]。

- **【波动率缩放仓位（vol-target 型）的三条结构事实 —— 读源码即可确立，不必先回测】**（study [[ETF动量]] q-9，base [[22152780_七星ETF轮动V1.7.2]]，满仓小市值臂，TRAIN 2022–2023，冻结零滑点 ⚠）：该基类的 `enable_dynamic_position`（第 186 行开关）按 **沪深300 20 日收益率标准差** 把 sleeve 的**目标名义**从 1.0 线性压到 0.5（vol<0.015→1.0；vol>0.035→0.5），单一消费点为 `strategy_value = total_value * proportion * position_ratio`，且 `available_cash = max(0, strategy_value − current_value)`。⇒ **(1) 天花板等于基准值 ⇒ 这类开关只能减仓、永远不能加仓**，故它对收益的贡献**结构上不可能为正**，只可能为 0 或负 —— 任何「它提升了收益」的读数都应先怀疑是别的东西；**(2) 阈值把它变成分段惰性件**：只要 20 日波动低于下沿（此例 1.5%/日）它就**精确恒等于关闭状态**，而这在一个两年窗里往往是绝大多数交易日 ⇒ **它的全部效应集中在极少数压力 episode 上，天然带 n≈1 的 episode-risk**，与「n=4 次日历触发」那类小样本风险**性质不同、不可并列**；**(3) `max(0, …)` 的现金地板意味着它节流的是新增部署、并不强制卖出** ⇒ 在**上涨**途中它压住加仓、在**下跌**途中它基本不动手，行为上更像「recovery 期的减速带」而非「危机期的刹车」。**实测结果与这三条自洽且值得记住**：打开后 **annual 变化 0.00pp**（total 194.8193 vs 194.82，五位有效数字相同）而 **maxDD −1.8854pp** —— 即在这一个窗上它是一个**收益成本字面为零**的回撤削减器；机理是它在同一段高波动区间里**同时**削掉了下跌与随后的反弹，两者净额抵消。⚠ 该「免费」判断**仅对本窗、本臂成立**，且效应集中在单一 episode（n≈1），**不得外推为一般结论**；⚠ 与之相邻的另一条纪律：它与另一个回撤控制件的 **ΔmaxDD 不可相加**（两者压到同一条 episode 地板上），见 [[止损模块]]；⚠ 绝对水平产自满仓微盘 × 零滑点台，不可读作可实现。溯源 [[ETF动量]] q-9。

- **【全仓库通用 · 结构性陷阱】一本大部分时间在现金里的账本，无法靠「加仓」去过 sharpe 闸 —— 因为闸门的门槛随暴露同比上升**（study [[三进兵]] q-2，base [[e4eb8dca_三进兵]]，TRAIN 2022–2023，冻结零滑点 ⚠，⚠ **该家族每条臂都 DQ、`objective` 不携带信息**）：把闸门写开就能看见 —— `sharpe = (annual − rf) / vol`（该恒等式在本家族**五条读数**上把 JQ 复现到三位有效数字，反解 rf 一致落在 **3.997%–4.003%**，即 **rf ≈ 4.00%/年**），于是 `sharpe ≥ 2.5` 等价于 **`annual ≥ rf + 2.5 × vol`**。**vol 随暴露近似线性上升，所以门槛也随之线性上升**：同一策略在基线暴露下要 **24.1%** 年化（vol 0.0805）、把仓位放大 1.43× 后要 **31.6%**（vol 0.1104）、满仓（B&H 同一篮子）要 **81.6%**（vol 0.3103）。实测证据极其干净：恢复作者原意的分仓（单行、去掉 `*1.5`）后，**成交账本逐笔不变（27 笔 5W/22L）、`avg_trade_return` 到小数点后四位相同、最深回撤窗端点逐日相同**，而 **maxDD / beta / turnover 三条按同一系数 1.429 放大**（vol 1.371）—— 一次近乎教科书式的**纯尺度变换**，sharpe 只动了 +0.109。→ **两条可复用纪律**：**(1)** 看到「低回撤 + 低 vol + 低 beta」时，先用 `vol / beta` 对**同池买入持有**求比值反解**实际暴露**（此例 vol 比 0.26 / beta 比 0.11 ⇒ 常年只有约 **11–26%** 仓位），再决定那个低回撤该记给**风控**还是记给**没有仓位**（此例是后者：9% 的 maxDD 是缺席，不是保护）；**(2)** **「加仓就能把它做上去」在 sharpe 类闸门下是错的** —— 加仓同时抬高分子和分母的门槛，只有**先有 edge** 才谈得上仓位；反过来，把一个期望近似为零的账本放大，放大的只有噪声（此例三条量级预测——annual 上升 / maxDD 20–35% / vol·beta 放大 2.5–4×——**全部落空**）。⚠ 本条描述的是**闸门算术**，与 vol-target 类部件（上一条）无关，两者不要混读。溯源 [[三进兵]] q-2 / 收口。

- **【全仓库通用 · 收口纪律】一个「全员 DQ」的家族判决必须先分开两种病：「没有 edge」与「有 edge、但绝对波动装不进闸」**（study [[红利低频]] baseline / q-1，base [[93379f98_低换手红利策略]]，TRAIN 2022–2023，冻结零滑点 ⚠，⚠ 全窗 DQ ⇒ **`objective` 不携带比较信息，全部结论由 annual/sharpe/vol/maxDD+回撤窗/alpha/beta/information/笔数 承载**）：承接上一条的闸门算术 `sharpe ≥ 2.5 ⟺ annual ≥ rf + 2.5×vol`（rf = 4.00%）—— **同一个「❌」在两种完全不同的账本上长得一模一样**。对照：[[三进兵]] 缺口 ~24pp，账本期望近似为零、9% 的低回撤是**缺席**而非保护 ⇒ 真的**没有 edge**；[[红利低频]] 缺口 **≈13.9pp**（vol 13.34% ⇒ 门槛 37.34%，实测 23.41%），但它 2022/2023/2024 **三个 regime 全部**跑出实质超额（alpha 29.7 / 30.5 / 35.4%，information 2.72 / 2.91 / 2.21），且**同一本账的 `excess_return_sharpe` = 3.043** —— 在基准相对口径下轻松过线，只在**绝对**夏普口径下以 1.4555 落闸。→ **判据（不必额外回测，payload 即可算）**：把 `excess_return_sharpe` / `information` 与绝对 `sharpe` **并排看**——两者背离（相对口径高、绝对口径低）指向「**低 beta 的 edge + 绝对波动过高**」，两者同低才是「无 edge」。**这道绝对闸对低 beta 书有系统性偏见**：它按 `vol` 而非按超额的稳定性计分。⚠ **这是刻画不是修复**：随之而来的「把 vol 压下去」属 auto-enhance，且本例的方差分解（系统性 6.9% / 特质 11.4% / 特质占方差 73%，反解基准 vol ≈16.1%）显示所需的 7.76% 只比**系统性地板**高 0.85pp ⇒ **单靠分散不可行**（特质须 −69%、有效 N ×10，还没算 β 随 N 上抬）。⚠ 绝对水平产自零滑点台；本例零滑点折价已定尺寸为 ~0.5–1.0pp/年，**远小于缺口、不是成因**——照实说，不做条件反射式归咎。溯源 [[红利低频]] baseline / q-1。

- **【接上条 · 两处更新：一次数值更正 + 「有 edge 那一侧」的收口形状】**（study [[红利低频]] q-4 / q-3 / 收口，同一 base、同一窗，冻结零滑点 ⚠）：**(A) 上一条括号里的方差分解已作废、按下列数字读**（append-only，故旧文保留可见而不静默覆盖）——上一条用的基准 vol ≈16.1% 是由 `information`/`alpha` **反解出来的估计**；q-4 回收的 payload 里 JQ **直报** `benchmark_volatility = **0.172185**` ⇒ 系统性 vol ~~6.9%~~ → **7.40%**、特质 vol ~~11.4%~~ → **11.09%**、特质占方差 ~~73%~~ → **69%**、门槛所需的 7.76% 高出系统性地板 ~~0.85pp~~ → **0.36pp**、纯分散化路线 ~~特质 −69% / 有效 N ×10~~ → **特质 −79% / 有效 N ≈×22**。**方向不变而是加强**：那条「靠分散去闸」的路径在算术上**基本关死**。**可复用的方法学纪律**：**由派生统计量反解出来的量，在平台直报同一量的那一刻必须被替换；在被替换之前必须明写为估计值。** **(B) 「有 edge、只是绝对波动装不进闸」这一侧长什么样 —— 一个可引用的完整样本**：该家族最高的 alpha（**35.42%**）与最高的 sharpe（**2.31**）出现在**上涨年**，那一年低 beta 机制是**反着**作用的（beta 信用 **−7.32pp**），它仍打出 **+30.3pp** 原始超额 ⇒ **「跌市里靠低 beta 白捡 alpha」这个最常见的替代解释可以被一个反向 regime 子窗一次性排除**（判别法见 [[多因子模型]]「`alpha` 含 beta 信用」条）。而 edge 本身是**两个因子的交互**（既分红、又被冷落），拆开后两条单腿只有 **−0.20%** 与 **11.95%** 年化（见 [[多因子模型]]「秩相加融合选出的是第三个集合」条）。→ **收口纪律**：写「全员 DQ」的判决时，**「无 edge」与「有 edge + 绝对波动过高」必须落成两句不同的话**，并各自给出**缺口的数值形状**（此例 **13.9pp**，且所需 vol 只比系统性地板高 **0.36pp** ⇒ **硬风格天花板**；对照 [[三进兵]] **~24pp** + 账本期望近零 ⇒ **真的没有 edge**）；只有前者才有「降波」这条 auto-enhance 话题，而且要连同「纯分散化不可行」一起交出去。⚠ 全部绝对水平产自零滑点台，不可读作可实现。溯源 [[红利低频]] q-4 / q-3 / 收口。

- **【全仓库通用 · 收口纪律，第三型】一条「对 regime 不变、且对每一次部件消融都不变」的波动率，是这本账的结构属性，不是伪影 —— 而当闸门恰好只由它决定时，任何单部件消融都不可能修好它**（study [[网格]] baseline / q-1 / q-2 / q-3，base [[32021d45_【网格交易策略-年化30%+】-网格大法好，熊市]]，TRAIN 2022–2023，冻结零滑点 ⚠，⚠ 全窗 DQ ⇒ **`objective` 不携带比较信息，全部结论由 annual/sharpe/vol/maxDD+回撤窗/笔数 W-L/P-L/turnover/beta/alpha/information 承载**）：实测五个口子上的 `vol` —— **26.57%（2022）/ 27.47%（至 2023-H1）/ 26.14%（全窗）/ 27.00%（修掉一处整卷 `return` 的 bug 之后）/ 27.05%（关掉指数 2 日 −3% 整卷止损之后）** —— 全部落在 **26–27.1%** 的一条窄带里，**而同期 annual 在 20.42%–33.79% 之间摆动、maxDD 在 19.68%–28.99% 之间摆动**。⇒ 收益和回撤对部件敏感，**波动率不敏感**。因为闸门是 `annual ≥ rf + 2.5 × vol`（此例 rf **4.000%**，第五次独立确认：`(0.35029932−0.04)/0.26135842 = 1.187256` 与 JQ 自报 sharpe **吻合到六位小数**），门槛被钉在 **69.34%**、实测 33.79% ⇒ 缺口 **≈35.6pp**。→ **两条可复用纪律**：**(1) 收口前把 `vol` 在所有已跑的臂上列成一列看** —— 若它是一条直线，则「再消融一个部件就能过闸」在**算术上**已经被排除，剩下的只有「换宇宙 / 换构造」这类**结构改动**（属 auto-enhance / research，不属解剖）；若它随部件动，才谈得上部件级降波。**(2) 结构性波动的成因要用方差分解定性，而不是猜** —— 此例用 JQ **直报**的 `benchmark_volatility 0.172185`（不反解）得系统性 `0.72619×0.172185 =` **12.50%**、特质 **22.95%**、**特质占方差 77.1%** ⇒ 读作**集中度伪影**（5 只票、2 个行业码）而非硬因子天花板，与 [[红利低频]]（特质 69%、所需 vol 只比系统性地板高 0.36pp ⇒ **硬风格天花板**）形成**同为「全员 DQ」但成因相反**的一对。⚠ 但「集中度伪影」不等于「分散就能修好」：此例系统性地板 **12.50%** 与闸门所需的 **12.41%** 几乎相等 ⇒ **把特质压到 0 才勉强到地板，纯分散在数学上刚好够不着**。⚠ 附带一条结构事实：该基类**单笔名义金额硬编码**（`unit_value = g.cash/40` = 25,000，全文不出现 `context.portfolio.total_value`）⇒ 单票最大暴露永远是**初始**资金的 25%、**账本不会复利** —— 这解释了它的**水平**，但**不解释**上面那条不变的 vol；两者不要混读。溯源 [[网格]] 收口。

- **⚠ 把仓位除以「合格候选数」而不是「预期槽位数」，会让权重上不封顶 —— 先查除数，再把集中度归因给选股规则**：[[趋势技术]] 的基类写 `cash_per = context.portfolio.available_cash / len(target_list)`（第 203 行），而 `target_list` 是**当日实际合格的候选**、上限只有 `g.M − 已持仓数` 且**常常更短**。⇒ 从空仓出发、当日只有 1 只票合格时，**那只票拿到约 100% 的组合**；名义上的「5 只等权」在代码里**并不存在**，权重上界是 **1.0**。可观测后果：该账本的**特质波动占方差 90.46%**（系统性 = `beta 0.36493 × benchmark_vol 0.172185` = 6.284%、特质 19.350%），是本项目迄今最集中的一本账（对比 [[网格]] 77.1%）。**可复用的检查顺序**：见到极端特质份额时，**先读下单那一行的除数**，再考虑「选股规则太集中」这类解释——本例里除数就足以解释全部现象。**并与尺度旋钮区分**：该除数按组合实时现金计算（**会复利**），因此它是**真结构旋钮**，不同于 [[三进兵]] 已确立的「纯仓位缩放换不出夏普闸」的那种尺度旋钮；也不同于 [[网格]] 的固定名义金额（`g.cash/40`，账本不复利）。⚠ 尚未测量：把除数改成 `g.M` 的受控消融是 [[趋势技术]] §4 的排队实验，本条目前只是**代码级机械推断**。溯源 [[趋势技术]] 基线锚点 + `study-q-struct`。
- **配套：全员 DQ 的家族，判词必须区分「没有 edge」和「有 edge 但绝对波动太大」**（本页闸门算术的常设读法）。[[趋势技术]] 是第 **三** 个「`excess_return_sharpe` 过 2.5、绝对夏普闸落」的全 DQ 家族（3.119，缺口只有 11.32pp；rf=0.04 第六次确认，`(0.43543171 − 0.04)/0.20344893 = 1.9436`）⇒ 这类判决现在应归因于**冻结闸门选了绝对夏普**这件事本身，而不是若干互不相干的策略各自失败。⚠ 与上一条配对读：此例所需 vol 上限 `(0.43543 − 0.04)/2.5 =` **15.82%**、系统性地板只有 **6.284%** ⇒ **纯分散在数学上够得着**（与 [[网格]] 的「刚好够不着」相反）——但那属 auto-enhance 的设计问题，不是解剖结论。溯源 [[趋势技术]]。

- **⚠ 槽位数同时也是「排序是否被消费」的开关：`candidates[:g.M]` 里若合格池 ≤ `g.M`，排序方向完全不起作用**（study [[趋势技术]] q-1，TRAIN 2022–2023，冻结零滑点 ⚠，⚠ 两臂皆 DQ ⇒ 不报 Δobjective；⚠ 该臂为 `recover-result.js` 找回，溯源强但不密不透风）：把候选排序反向后 annual 只动 **−4.29pp**、sharpe −0.2035，而 **maxDD −0.004pp 且回撤窗端点逐日相同**、vol −0.20pp、beta 反降 —— 因为 `buy_list = candidates[:g.M]`（`g.M=5`）后 `market_open` 再按 `num_to_buy` 切一次，**顺序只在 `num_to_buy < len(candidates)` 时才咬合**。⇒ 与本页「除数用合格候选数」那一条**成对读**：**`g.M` 这个槽位常数既决定单票权重上限、又决定排序有没有被消费**，两种效应都必须先看**合格池规模的分布**（多数策略已在日志里打出，是零回测检查）才能归因。溯源 [[趋势技术]] `study-q-1`。

- **【上面那条「vol-target 仓位」的跨纪元复现 —— 形态稳住了，但两个纪元的数字不可并列】**（enhance [[etfmom-005]]，同一 base [[22152780_七星ETF轮动V1.7.2]] 的满仓小市值臂，**epoch 6**（首次钉死股票侧 `set_order_cost`），冻结零滑点 ⚠⚠）：把 `enable_dynamic_position` 叠在「满仓 + 1/4 月日历规则」臂上（相对 etfmom-004 **一行 diff**），epoch 6 上测得 **annual 77.64→76.47（−1.17pp）、maxDD 13.05→11.31（−1.74pp）、sharpe 3.10→3.20**。与 epoch 2 的 q-9（annual **0.00pp** / maxDD −1.89pp）**形态一致**：收益轴近惰性、回撤轴实质改善 ⇒ 上面那条「它在这个窗上是一个收益成本极低的回撤削减器」在**换了成本口径之后仍然站得住**，这是该结论目前最强的一次加固。**但两条纪律必须随行**：**(1)** `measurementValid(5) = false` ⇒ **epoch 2 的 0.00pp 与 epoch 6 的 −1.17pp 不可并列相减**，可迁移的是**形态**（哪条轴动、哪条轴不动），不是量值；**(2)** 上条列的三条结构事实（天花板 = 基准 1.0 ⇒ 只能减仓；低波动区间精确惰性；`max(0,…)` 只节流部署不强制卖出）是**读源码得到的**，因此**不随纪元变化**，它们仍是解释这次复现的正确框架。⚠ **n≈1 episode-risk 同样跨纪元继承** —— 效应仍集中在少数高波动 episode 上。⚠ 该臂是**满仓微盘 × 零滑点台**，绝对水平（TRAIN total 210.94% / VAL total 544.14%）**绝不可读作可实现**；只有同腿、**同纪元**臂间的 Δ 可信。溯源 [[etfmom-005]]（VAL 侧的归因保留意见见 [[小市值因子]] 同轮条目）。
