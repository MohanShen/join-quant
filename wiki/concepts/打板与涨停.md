# 打板与涨停

**定义**：以「涨停」为核心事件的短线交易范式——围绕首板（昨日涨停、前日未涨停）、一进二（首板冲二板）、连板龙头、炸板回封等形态，在集合竞价或尾盘介入强势股，次日了结。属高换手、强情绪驱动的策略结构。

## ⚠ 绩效可信度警示（务必先读）
打板策略的回测**系统性高估**，本组多数标的年化数百到数千倍、夏普 9–107，几乎都不可实现，原因：
- **涨停成交假设失真**：回测假定能在涨停板/集合竞价买到，实盘常一字封板买不进；
- **短回测窗口**：多为 2026-04/05 起约 1 个月，外推到「年化」放大极端；
- **滑点/冲击成本**被严重低估。

因此本页**不做绝对绩效横评**；阅读时以「逻辑差异」为主，绩效仅作相对参考。区间较长、读数较温和者（[[9106ccaf_首板炸板回封]] 2019 起/回撤4%、[[0ff0ddba_连板涨停交易系统]]、[[b518f737_连板龙头策略]] 回撤50%）相对更有信息量。

## 共性做法
- **选股**：首板/连板/涨停基因形态 + 市值过滤（多为 30–520 亿）+ 成交额/换手/竞价涨幅过滤。
- **介入**：集合竞价后（9:26/9:27）或尾盘（14:50）；连板龙头用限价排板。
- **了结**：分钟止盈 + 尾盘 MA5 止损 + 次日定时卖出，普遍持仓极短（T+1）。

## 观察
- **本组第一份归一化台上的实测机理数据（不再只有指标）**（study [[打板短线]] q-3，base [[439385b4_首板高开低开弱转强混合]]，2022 单年，冻结零滑点 ⚠）：`win_ratio 69.87%`（109 胜 / 47 负）、`profit_loss_ratio 2.28`、**`avg_position_days 1.51`**、`turnover_rate 0.3061`、`day_win_ratio 54.13%`、`sortino 13.44`、`algorithm_volatility 0.586`。含义：这类「昨日首板 → 次日竞价接力」并**不是**靠少数暴利尾巴，而是**高胜率 × 正盈亏比**的组合；`avg_position_days 1.51` 把本页「持仓极短（T+1）」的共性描述从推断变成实测。⚠ 这些数字与该策略的年化一样建立在**零滑点 + 假定能在竞价买到昨日涨停股**之上——胜率与盈亏比在真实成交约束下会先于收益率恶化（买不进的多半正是最强的那批票，即幸存下来的样本会被系统性削弱），故不可当作可实现读数。溯源 [[打板短线]] q-3。
- **打板类的头条年化可能整段来自单一年份**（study [[打板短线]] q-3）：家族头名 base 在冻结 TRAIN 2022–2023 的 +424.33% 总回报中，**2022 单年就有 +442.51%**（sharpe 8.01、maxDD 25.10%），反解 2023 约 **−3.35%**。→ 读本页任何 ⚠ 头条时，除了成交假设，还应默认追问**年度分布**；两年合并的年化对情绪驱动风格尤其容易掩盖「一年吃饱、一年归零」。同一形态在机理无关的 [[多因子ML]] 上同向出现（方法学见 [[多策略组合]]）。溯源 [[打板短线]] q-3。
- **【工具 · 全仓库适用】`slow-skipped` 的回测结果可零成本回收，并且回收到的字段比执行器多得多**（study [[打板短线]] 记录）：执行器有自己的轮询上限（默认 20 分钟），超时即 emit `slow-skipped`，但 **JQ 端往往已经计费并把该跑跑完了**。回收路径：读该 algorithm 的 buildList 找到状态「完成」的行 → 取 `backtestId` → `POST /algorithm/backtest/stats?backtestId=<id>&ajax=1`。两点后果：(a) 已被记为 `slow-skipped` 的历史成员（如 `harness/normalize-train.tsv` 里长期挂着的两条）**可能可以直接补回，无需重跑**（待逐个验证，只标不裁决）；(b) 这个 payload 含 `win_ratio / profit_loss_ratio / avg_position_days / turnover_rate / day_win_ratio / sortino / algorithm_volatility`，而执行器的 10 列 SUMMARY 全部丢弃——**「本台做不了 probe 类问题」这一长期假设由此被部分推翻**，消融实验此后可以问「被改动的是胜率还是盈亏比」「退出规则是否真的改变了持仓天数」「换手变了多少 ⇒ 零滑点高估幅度变了多少」。⚠ 记账纪律：这样取回的结果**不走 harness §5 的 `SUMMARY status=completed` 契约**，必须在发现里显式标注 recovered-result 与 backtestId。溯源 [[打板短线]] q-3。
- **重量级打板基类会撞上执行器轮询上限**（同上）：[[439385b4_首板高开低开弱转强混合]] 的**单年**回测只计费约 8 JQ 分钟，wall-clock 却超过 20 分钟（每根 bar 对全 A 首板候选逐票取竞价 / 101 日历史 / 估值）。此类家族的每次实验都需显式放宽轮询上限（`--max-poll-min 35`），否则会白烧配额并返回 `slow-skipped`。溯源 [[打板短线]]。
