# 资产配置

**注册于 2026-10-30**，来源是 `screen/qita` 那轮筛选：`其他` 这个 catch-all 桶里有 95 本书、全部在 epoch 9 上测过、30 本过闸，却因为没有家族页而对 `family-queue` 和 `integrate-eligible` **完全不可见**。三个 `post-screener` 读完那 30 本的源码后，**batch 2 与 batch 3 各自独立**地指出「多资产配置」是现有 13 族完全没有覆盖的机制——而且用的是**不同的名字**（静态多资产再平衡 / 全天候风险平价 / 回撤档位杠杆 vs 资产配置-固定权重 ×3 / 资产配置-优化器）。CLAUDE.md 里记的那 71 个「筛出来但没注册」的候选族里也有 all-weather / risk parity。三条互相独立的证据指向同一个缺口，所以注册。

## 1. 基类 (base archetype)

`4a67a7b0`：5 只 ETF 各 20% 固定权重，每 10 个交易日把持仓拉回目标权重。文件里**没有任何信号**——没有动量、没有均线、没有基本面筛子。这是本族机制的下限形态，也是它与其余 12 族的分界：别的族都在**选**标的，本族在**配**权重。

⚠ **base 的池子并不覆盖 edge claim 里列的资产类别。** 4a67a7b0 的五只是 515450 红利低波 / 513630 港股红利低波 / 513100 纳指 / 518880 黄金 / 513650 标普——**没有债，没有商品**，而且两只美股仓位在 2024 上日收益相关 **0.89**（u-2 实测），实际上是同一个敞口，有效资产数约 4、其中约 40% 在美股。所以「A股宽基 / 债 / 黄金 / 海外股 / 商品」描述的是**本族**（七名成员合起来），不是 base（`edge.claim` 已于 2026-10-31 u-1 后改写为只声称 base 的红利 × 黄金 × 美股池）；对 base 做的任何分解，结论只覆盖「红利 × 黄金 × 美股」这三类。债的作用要看 imp-4 / u-4 / b1531180、c913387f，不能从 base 推。

⚠⚠ **本族不是一个血缘（lineage），这与仓库里「family = lineage」的定义冲突，必须写明白。** 其余 12 族的成员共享代码祖先，所以 `utils/family-match.js`（对 `base:` 做归一化代码行的 Jaccard 重叠）能给出候选。本族七名成员彼此不共享代码，因此：

- **`family-match` 永远不会把新成员匹配到本族**。它只会继续 abstain。本族的新成员只能靠人或 `/ingest-strategy` 发现，`node utils/family-match.js --pending` 不会提醒。
- **§3 的组内比较是跨实现的**，不是同一本书的变体比较。读 §3 的横评时要记住这一点：7 行里的差异包含「不同的权重算法」，而不只是参数差异。
- 另一个同样合理的归档方式是把 `资产配置` 放在**类型层**（`wiki/types/`，universe × turnover 的坐标）而不是家族层。注册成家族是 2026-10-30 的人工决定；如果以后类型层要收走它，上面这一段就是改动的依据。

## 4. 待研究 / 空白 (research gaps)
- ⚠⚠ **【本轮不要花 VAL】** exit gate 对本族显示的理由是「never validated — /run-family must finalize on VAL first」，那是 gate 的措辞，不是本族的研究顺序。本族注册于 2026-10-30，`edge` 仍是 `proposed`、realizability **未测**、零次 study —— 在这个状态下花掉 VAL，确认的是**一个水平数字**（base 的 0.2346 在 2025 上还成不成立），而不是**机制**。而 VAL 是每 (family, bench) 一次、不可撤回，本仓库已有记录在册的教训：[[小市值]] 的 epoch-9 VAL 花在冠军上、回来 sharpe 0.83，而那本书的 TRAIN 水平后来被证明有 1/3 来自单日事件。**顺序应为**：(1) 跑 edge 的 `test:`（1 次回测，判 sharpe）→ (2) 一次 liq 测 realizability → (3) 只有当 edge 至少 `measured` 且 R ≥ 2 时，才考虑 VAL。若本轮结束时 edge 仍未成立，正确做法是**记一条 `valDeclined` 并写明理由**，而不是把 VAL 花掉。

- **[最高优先，1 次回测] 跑 edge 的 `test:`**：把 base 的权重向量换成「全仓持有池中单一最好资产」。这是本族 `edge: proposed` 转 `measured` 或 `refuted` 的唯一一步，而且只要一次回测。⚠ 判据必须是 **sharpe**，理由写在 `test:` 里。
- **[2026-10-31，u-2 之后] edge test 的 X 已在运行前声明 = 518880 黄金**（u-2 测得的事后最佳单资产，2024 sharpe 1.79；预期 < 2.47）。u-2 的 DR 0.630 只是**支持** claim，不是 `test:` 本身，所以 edge 保持 `proposed`，直到 u-1 在台上跑完。⚠ 若单资产赢了，要写明控制组拿到了「事后挑选」的优势。
- **[阻塞 exit gate] realizability 未测**：本族七本都没做过可成交性测量。七本都是宽基/跨资产 ETF、日成交额远高于个股族，所以**先验**是容易成交的——但 [[大小盘轮动]] 的 liq-1 得出的是反直觉结论（地板一个名字都没剔掉），而 [[ETF溢价]] 的是 8.44→1.10，所以先验不能当测量。要一次 liq 跑在 base 自己的可行性下限上。

- **[新缺口，u-1 暴露] 债 / 商品腿未测**：edge 只在红利 × 黄金 × 美股上成立。claim 要扩到「债」必须靠 imp-4（原池 + 511010）与 u-4（通用池），二者都不能因 u-1 通过而跳过；u-4 同时是「池子是否事后选的」唯一检验（作者 2026-06-15 发帖，池子看见过 2024）。
