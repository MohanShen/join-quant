# 红利低频 — strategy family

**一句话**：按「近一年现金股息率」选高股息股，低频（月度级）持有等权组合；基类另叠一个「20日低换手」排名。

## 1. 基类 (base archetype)   ← [[93379f98_低换手红利策略]]，源码快照 `study/红利低频/baseline.py`
- **Universe 选股池**：全 A 股，排除科创板（688）与当日停牌；**不滤 ST、不滤新股**。实际可选集 = 近 365 天内有「实施方案」现金分红的股票（股息率 > 0）。
- **交易频率**：每 25 个交易日调仓一次（`run_daily` 14:50 计数，第 1、26、51… 日触发）。
- **交易机制**：
  - *入场 / 择时*：无择时，永远满仓。
  - *选股*：股息率TTM = 近 365 天 `STK_XR_XD.bonus_ratio_rmb/10`（每股派息，按股权登记日）÷ 前一日收盘价；20 日平均 `turnover_ratio`。两者各自排名（股息率降序、换手率升序），综合分 = 3×股息率名次 + 3×换手率名次（权重相等），取前 10。
  - *调仓*：卖出不在目标里的持仓，目标股等权 `total_value/10` 调整。
  - *止损 / 风控*：无。
- **基线绩效**（frozen harness epoch 6, TRAIN 2022–2023）：
  | objective | sharpe | annual% | maxDD% | total% | window |
  |---|---|---|---|---|---|
  | 0.1348 | 1.46 | 22.61 | 9.13 | 50.26 | train |
  | 0.2435 | 2.05 | 35.10 | 10.75 | 82.51 | **val**（epoch 6 唯一一次，[[study-val-1]]） |
- **为什么有效**（溯源 [[study-q-1]] [[study-q-2]] [[study-q-8]] [[study-q-9]] [[study-q-4]]）：**两条腿缺一不可，且互补而非相加**。只按股息率 obj −0.2658（2022 熊市 −14.3%，困境高股息股 = 价值陷阱，且不是 ST 造成的，q-7）；只按低换手 obj 0.0028；等权排名和 0.1348。**低换手腿**（`流动性溢价`，measured）是熊市防御——2022 基类 +21.4% 而基准 −21.6%；**股息率腿**（measured，作为联合排名腿）主要在 2023 与 VAL 的红利行情里供给收益。信号集中在两者**同时极端**的少数票（5 只 ≈ 10 只，20 只稀释，q-5），粗筛低换手三分位再挑最高股息不行（q-8）。
- **脆弱点**：1:1 权重是单峰（3:1 / 1:3 各 −0.08，q-9）；调仓相位不敏感（q-6）；换手窗口 20 日最好，60 日优于 10 日（q-10）。VAL 未见该峰带来的衰减。
- **不是小市值**：限定中证800 仍保留 ~60% objective、回撤不变（q-3）——与 `规模因子` 家族在 edge 上不冗余。
- **⚠ 现实性 / 容量**：14:50 以日线价撮合（零滑点 ⚠）；低换手股流动性偏弱，但 10 只 × 25 日一换的换手很低，冻结台 `order_volume_ratio=0.05` 已限量。基类不滤 ST —— 高股息 ST 股若入选即为风险敞口。

## 6. 研究问答 (study-log)
- **[Q b-0]** baseline reproduction（type: probe）
  **→** baseline.py with the frozen OVERRIDE reproduces the epoch-6 ledger row to the basis point in 67s of backtest time
  **⇒** no rerun-drift control is needed for Δ > 0.01 obj, and at ~1 min/run every sweep in the queue is affordable within one day — run both arms of each sweep rather than one
  （Δ obj 0.1348 = ledger epoch-6 row exactly (annual 22.61 / sharpe 1.46 / maxdd 9.13)；confidence high） 溯源 [[study-b-0]]
- **[Q q-1]** turnover rank (weight 3 -> 0)（type: ablation）
  **→** top-10 by dividend-yield TTM alone earns nothing (annual -0.20%, maxdd 26.38%): the whole base result depends on the low-turnover rank
  **⇒** the 股息率 claim as worded (excess from the yield end, not the turnover rank) is refuted; the open question is WHY raw top yield fails — test whether ST/distressed names (yield inflated by a collapsed price) are the trap (q-7) and whether yield only works inside the low-turnover subset (q-8)
  （Δ obj 0.1348 -> -0.2658 (Δ -0.4006); sharpe 1.46 -> -0.20; maxdd 9.13 -> 26.38; annual 22.61 -> -0.20；confidence high） edge: 股息率 溯源 [[study-q-1]]
- **[Q q-2]** dividend-yield rank (weight 3 -> 0; payer pool kept)（type: ablation）
  **→** low 20d turnover among dividend payers alone gives annual 11.56% at maxdd 11.28% — positive but far below the combination; removing the yield rank costs 0.132 obj
  **⇒** the two ranks are complementary, not additive: yield alone -0.2658, turnover alone 0.0028, both 0.1348. Improve ideas must keep BOTH ranks; the rank weights (3:3) become an on-mechanism sweep worth running (q-9)
  （Δ obj 0.1348 -> 0.0028 (Δ -0.1320); sharpe 1.46 -> 0.55; maxdd 9.13 -> 11.28; annual 22.61 -> 11.56；confidence high） edge: 流动性溢价 溯源 [[study-q-2]]
- **[Q q-7]** ST/退/次新 filter on the yield-only book（type: ablation）
  **→** removing ST/delisting/<250-day listings leaves yield-only as bad as before (annual -0.47%, maxdd 25.42%); the picks changed but the loss did not
  **⇒** closed: ST/新股 hygiene is not what the turnover rank supplies, so i-2 (the same filter on the base) is not expected to move it much and drops to last. The value trap sits in non-ST high-yield names — the conditional test q-8 is now the direct question
  （Δ vs q-1: obj -0.2658 -> -0.2589 (Δ +0.0069); annual -0.20 -> -0.47; maxdd 26.38 -> 25.42. vs base Δobj -0.3937；confidence high） edge: 股息率 溯源 [[study-q-7]]
- **[Q q-8]** yield rank inside 20d-turnover terciles (low: q-8a, high: q-8b)（type: isolate）
  **→** pure yield within the lowest-turnover tercile still falls well short of the base (-0.0663 vs 0.1348) while within the highest tercile it tracks the market crash (-0.4574); turnover level orders the results monotonically (high tercile < low tercile < rank-sum base)
  **⇒** the conditional 股息率 claim is refuted: a coarse low-turnover screen plus max-yield is not the mechanism — the base needs names EXTREME on turnover (q-2 alone +14.26 in 2022), so turnover rank is the load-bearing leg and yield a secondary sort.   （Δ q-8a obj -0.0663 (Δ -0.2011; annual 10.11, maxdd 16.74, sharpe 0.34); q-8b obj -0.4574 (Δ -0.5922; annual -13.06, maxdd 32.67, sharpe -0.72). 2022 cum: q-8a -3.26, q-8b -28.75, q-2 +14.26, bench -30.55；confidence high） edge: 股息率 溯源 [[study-q-8]]
- **[Q q-9]** rank weights dy:turnover (1:1 base -> 3:1, 1:3)（type: sweep）
  **→** objective peaks at equal weights and falls ~0.08 symmetrically when either rank is tilted 3x, i.e. a single sharp peak rather than a plateau; with the full sweep endpoints q-1 (-0.2658) and q-2 (0.0028) the curve is -0.27 / 0.06 / 0.13 / 0.05 / 0.00

  （Δ 3:1 obj 0.0570 (Δ -0.0778; annual 18.41, maxdd 12.71, sharpe 0.98); 1:3 obj 0.0532 (Δ -0.0816; annual 15.22, maxdd 9.90, sharpe 0.89); 1:1 0.1348；confidence high；⚠ overfit-cliff） edge: 流动性溢价 溯源 [[study-q-9]]
- **[Q q-3]** universe full-A -> CSI800 (000906) constituents（type: isolate）

  （Δ obj 0.1348 -> 0.0807 (Δ -0.0541); sharpe 1.46 -> 1.12; maxdd 9.13 -> 9.82; annual 22.61 -> 17.89；confidence high） edge: 流动性溢价 溯源 [[study-q-3]]

  **⇒** closes breadth as an improve lever (widening dilutes, narrowing to 5 does not gain); together with q-8 it says the signal lives at the joint extreme, so improve ideas should sharpen the ranking inputs (better yield/turnover measures, i-1) rather than change book size
  （Δ 5: obj 0.1203 (Δ -0.0145; annual 22.25, maxdd 10.22, sharpe 1.34); 20: obj 0.0774 (Δ -0.0574; annual 17.39, maxdd 9.65, sharpe 1.10)；confidence high） edge: 流动性溢价 溯源 [[study-q-5]]

  **→** shifting the 25-day rebalance calendar by 12 days changes the objective by only -0.006 with an identical drawdown
  **⇒** closed: the base result is not a lucky rebalance calendar, so the q-9 weight peak is the only fragility found so far and the rebalance cycle need not be re-swept by improve ideas
  （Δ obj 0.1348 -> 0.1289 (Δ -0.0059); sharpe 1.46 -> 1.43; maxdd 9.13 -> 9.12; annual 22.61 -> 22.01；confidence high） 溯源 [[study-q-6]]
- **[Q q-4]** 2022 vs 2023 split of the TRAIN curves (base, q-1, q-2, q-3)（type: regime）
