# 网格 — strategy family

**一句话**：**一套挂在硬编码「互联网+软件」两个行业码上、按固定名义金额分档补仓/止盈的网格**——而本轮解剖的产物是：**它的收益既不是网格收割、也不是熊市机器，而是一段六个月的板块行情**（2023-H1，+78.0%），2022 只贡献 +6.3% 且**胜负比为负**，2023-H2 回吐 −5.5%；它的 DQ 由一条**结构性固定的约 26% 波动率**造成，该波动率对 regime、对循环 bug 的修复、对指数择时开关**全都不变**，而收益只在行情里出现。

## 1. 基类 (base archetype)   ← study 2026-08-30 收口（溯源见 §6）

- **Universe 选股池**：硬编码行业字面量 `['I64','I65']`（互联网 / 软件），另有 **9 个备选行业码被注释掉**；成员由 `get_industry_stocks` 日期推导 → `get_fundamentals(pe_ratio < 50, market_cap desc, limit 30)` ⇒ **point-in-time、不是后见之明的固定 ticker 篮子**，但**行业本身的选择是未加解释的分析师自由度**。再从这 30 只里取 **5 只**进入 `g.buy_stock`。
- **交易频率**：`handle_data` 日线台，逐票逐日检查。实测极低 churn —— TRAIN 全窗 **118 笔平仓**、`turnover 0.010291/日`。
- **交易机制**：**入场/加仓** 首次建仓锚定 `g.initial_price` 后按跌幅分档 `order_target_value` 补仓；**止盈** 按涨幅分档减仓；**风控** 两层——① 指数（`000001.XSHG`）2 日跌幅 > 3% ⇒ **整卷跳过当日**（第 175–176 行）；② 个股累计收益 −20% 止损。
- **基线绩效**（frozen harness, TRAIN 2022–2023，729 日历日）：total **+78.86%** / annual **33.79%**（JQ 报 35.03%）/ sharpe **1.1873** / vol **0.261358** / maxDD **19.677%**（窗 **2022-02-10→2022-04-28**）/ **118 笔（83W/35L，win 70.34%）** / P/L **5.050** / turnover 0.010291 / beta 0.72619 / alpha 0.4640 / information 2.228 / **excess_return_sharpe 2.518** / sortino 1.885 / benchmark −30.55%（vol 0.172185）。**逐位复现归档 §3 行——全项目第 7 次连续精确复现。**
  ⚠ `objective` 在每条臂上都是 **DQ**、**不携带比较信息**；**本页任何地方都不报 Δobjective**。全部结论由 `annual` / `sharpe` / **`vol`** / `maxDD` + `max_drawdown_period` 端点 + 平仓笔数（W/L）+ `profit_loss_ratio` + `turnover` + `beta` / `alpha` / `information` 承载。

### 为什么（不）有效 —— 本家族的主产物

> **收益既不是网格收割也不是熊市机器，而是一段六个月的板块行情**（2023-H1，**+78.0%**，宇宙是互联网/软件），2022 贡献 **+6.3%** 且成交组合是**亏损面**（20W/23L），2023-H2 回吐 **−5.5%**。DQ 由一条**结构性固定的约 26% 波动率**造成——它对 **regime 不变**、对**循环 bug 的修复不变**、对**指数择时开关不变**——再配上一条只在行情里出现的收益。这条波动里 **77% 是特质的**，故读作**集中度伪影**（5 只票、2 个行业码）而非硬因子天花板。**在基准相对口径下它会过线**（`excess_return_sharpe 2.518`）；在冻结的绝对夏普闸上它差 **≈35.6pp**。

1. **「3 成员 / 0 过闸」其实是「2 份代码体、0 过闸」**（q-dup，零回测）。`32021d45` 与 `598050b9` **除两行 clone 头（postId / backtestId）外逐字节相同** —— 同 193 行、同 6909 字节、同文件名，只是两个月前后从两个社区帖各 clone 了一次。⇒ 家族的独立证据量 = **本基类 ×2 + `9498d93f_多ETF网格交易`（sharpe −0.90）**。**这是本批次第二个成员数虚高的家族**（继 [[三进兵]] 的 4 → 2）。
   - **⚠ 一条早先读数在此被更正，不是被确认。** 这对孪生行的归档读数在 `sharpe 1.19` / `maxDD 19.68` 上一致，却在 `annual` 上差 33.79 vs 33.84。早先曾把它读作 [[大小盘轮动]] 那条「buildList 总收益取整」伪影的旁证；**测量把它证伪了** —— 在 `days=729` 下对总收益取整只移动 annual **0.0001pp**，小**三个数量级**。真实成因是**年化分母差一天 + 截断**：同一笔总收益按 **728** 日年化 = **33.8453%** ⇒ 截断得 33.84；按 **729** 日 = **33.7918%** ⇒ 33.79。**我方实测精确落在 729 日那一侧。**

2. **DQ 有精确的算术形式（第五次独立确认 rf）**：`sharpe = (annual − rf) / vol`，`(0.35029932 − 0.04) / 0.26135842 = 1.187256`，与 JQ 自报的 sharpe **吻合到小数点后六位** ⇒ **rf = 4.000%/年**。于是闸门 `sharpe ≥ 2.5` 等价于 `annual ≥ 0.04 + 2.5 × 0.261358 =` **69.34%**，实测 **33.79%** ⇒ **缺口 ≈ 35.6pp，是本批次全 DQ 家族里最大的一个**。等价说法：在收益不变的前提下，需把 vol 从 **26.14% 压到 12.41%（−53%）**。

3. **那 26% 的波动 77% 是特质的 ⇒ 集中度伪影，不是硬因子天花板。** 用 JQ **自报**的 `benchmark_volatility 0.172185`（不是反解）：系统性 = `0.72619 × 0.172185` = **12.50%**，特质 = `sqrt(0.261358² − 0.1250²)` = **22.95%**，**特质占方差 77.1%**。⇒ 波动主要来自「**5 只票、2 个行业码**」这件事本身，而不是一条不可绕过的因子风险地板。

4. **⚠ 判决取决于口径：`excess_return_sharpe = 2.518`。** **按基准相对口径衡量，这条血统会过 2.5。** 它落闸**纯粹**因为闸门选的是绝对夏普而不是超额夏普 —— 这与「没有 edge」是**实质不同**的判决，本页任何地方都不得把它写成后者。

5. **收益集中在单个半年（q-3，PREFIX 子窗，无代码改动）。** 复利除法得增量：**2022 +6.29% / 2023-H1 +77.99% / 2023-H2 −5.45%**（校验 `1.062885 × 1.682776 = 1.788597` ✓）⇒ **两年回报的约 99% 来自 2023-H1**，恰是 A 股 TMT/AI 行情，而宇宙正是 `I64`+`I65`。**而 2022——正是家族标题「网格大法好，熊市不用跑」所主张的那个 regime——只有 +6.3%，成交组合是亏损面（20W/23L）、P/L 仅 1.155，却吃掉了两年 100% 的回撤**（三条子窗的最深回撤窗端点**完全相同**：2022-02-10→2022-04-28）。⇒ **熊市网格叙事不被数字支持。**

6. **波动率是结构性的，这是本页最硬的一条。** vol：**26.57%（2022）/ 27.47%（至 23-H1）/ 26.14%（全窗）**，并且在**修掉循环 bug 后 27.00%**、**关掉指数择时开关后 27.05%**。⇒ 唯一决定过闸与否的那个量，**对 regime 和对我们试过的每一处部件改动都不敏感** ⇒ 它是这本账的**固定结构属性**，**任何单部件消融都不可能修好它**。

7. **循环里的整卷 `return` 是真 bug，但不是活动度的限制项（q-1，证伪项触发）。** 把 179/182/186 三行 `return` 改成 `continue`：预注册的三条量级预测（笔数 ≥350 即 ≥3×、turnover ≥3×、vol ≥+5pp）**全部落空** —— 笔数**不升反降 −16.9%**（118→98）、turnover 仅 **+13.8%**、vol 仅 **+0.87pp**；只有 `|Δannual| ≥ 10pp` 一条成立（−10.94pp）。⇒ **「基线只交易到前几只票、因为循环整卷退出」这条推断是错的。** 那个 bug 确实值约 **11pp 年化 + 6.6pp 回撤**，但限制活动度的另有其物 —— 剩下的候选是**现金梯**（`unit_value = g.cash/40` = 固定 25,000，单票目标最多 10 units，叠加一个不断累积重复项的 `g.buy_stock`）。**对下游归因的直接后果**：不需要「测在一本退化的账上」这条 caveat；需要的是「**测在一本活动度由现金梯、而非由循环封顶的账上**」。

8. **指数 2 日 −3% 整卷止损：实质贡献者，但不是发动机、也不是波动源（q-2）。** 关掉它：annual **−13.37pp**、maxDD **+9.31pp**、vol **+0.91pp**、turnover **−36.7%**。方向都对，**量级全部不到预注册的杆**（需 annual ≤−20 / maxDD ≥+10 / vol ≥+3），且点名的**反向信息情形（去掉开关后 vol 反而下降）未出现**。⇒ 它提供约 **13pp 年化**与约 **9pp 的回撤压制**。最能说明问题的一点：**去掉它之后最深回撤窗端点与基线逐字节相同** —— 它连「最差回撤发生在**什么时候**」都没有改变，只改变了幅度。

9. **⚠ 一处必须更正、不可传播的表述：选股取的是「波动最低」的 5 只，不是「波动最高」。** 代码是 `Series(variance_list, index=stock_set).rank()` 后取 `s1[s1 < 6]`；pandas `rank()` **升序** ⇒ 名次 1–5 是**方差最小**的 5 只，与第 46 行注释「取波动率最高的2只」**相反**（注释连数量都不对）。
   **而且这是一处双重背离**：`variance()`（66–75 行）算的是 180 个**原始日收盘价**的 `E[p²] − E[p]²`，即**价格水平的方差**，量纲是元²、随价格平方缩放 —— 它会把一只 ¥80 的票排在一只 ¥8 的票之上，**与收益波动无关**。⇒ 这个选择器取的是**一个根本不是波动率度量的量**的**升序端**。

10. **文档与实现背离（网格步长本身）**：真实档位是**买 −8 / −16 / −24 / −32%**、**卖 +15 / +30 / +45 / +60%**（由 `bench=-0.08` / `+0.15` 配 `bench, 2b, 3b, 4b` 得出），而第 189 / 191 行注释写的是 −3/−5/−8/−12% 与 +5/10/15/20% ⇒ **实际网格比文档宽 2–3 倍**。

11. **`g.buy_stock` 从不清空 ⇒ 广告里的季度轮换并不存在。** 第 53 行是它唯一的写入点（`append`），8 次季度选股事件后它会长到约 **80 个重复条目**，使 `reset_position` 在第一个季度之后**失效** ⇒ **宇宙只累积、不轮换**。

12. **固定名义金额下单 ⇒ 这本账不会复利。** `unit_value = g.cash/40` = 硬编码 25,000；全文**没有出现** `context.portfolio.total_value` ⇒ 单票最大暴露永远是**初始**资金的 25%。（[[三进兵]] 已确立「仓位是一个换不出夏普闸的尺度旋钮」，此处**交叉引用、不重复推导**。）

13. **未发现前视**；**harness §3 过滤全缺**（无 ST/停牌/次新/涨跌停）。缓解：市值前 30 的大盘股使 ST 污染不太可能；**实质缺口是「停牌」与「涨跌停」两道闸**（见 §4，挂旗交人工）。

1. **现金梯 —— 活动度封顶的头号嫌疑（q-1 排除了循环之后）。** `unit_value = g.cash/40` 固定 25,000、单票目标 ≤ 10 units、`g.buy_stock` 累积重复项 ⇒ 可下单容量与账户价值脱钩。设计：把 `unit_value` 改为 `context.portfolio.total_value/40`（单处改动），看笔数 / turnover / vol 怎么动。**这是解释「为什么只有 118 笔」的剩余唯一候选，也是本家族剩余价值最高的一次实验。**
2. **网格宽度扫描（`bench` −0.08 vs 文档写的 −0.03）。** 实际档位比文档宽 2–3 倍（§1 第 10 条）。**q-1 之前这个实验不好解释**（活动度可能被循环 bug 压死）；**q-1 已证明账本并不退化，故现在可解释了**：扫 `bench ∈ {−0.03, −0.05, −0.08, −0.12}` 看是平台还是悬崖，以及 vol 是否随之动（若不动，则为 §1 第 6 条「结构性波动」再添一条证据）。
3. **倒过来的方差选择器 —— 需要两处改动，故是一次后续实验而非单一消融。** `rank()` 升序取的是**方差最小**的 5 只（§1 第 9 条），而那个「方差」还是**价格水平的离散度、根本不是波动率**。⇒ 完整的检验必须**同时**改**方向**（`rank(ascending=False)`）**和度量**（改成日收益率的标准差）。因为一次实验只改一处的纪律，这需要**两次**：先只改方向（保持错误的度量）、再改度量。**先做哪一个不影响结论，但两者都不做就无法判断「低方差选择」到底是设计还是笔误。**
4. **`9498d93f_多ETF网格交易` 是家族里第二份、完全未被触碰的代码体**（sharpe −0.90 / annual −9.46%）。本页所有实测数字都出自代码体 A；那份 ETF 网格**从未被解剖**，其 −0.90 是否同源于同一条结构性波动，未知。

**→ auto-enhance（不是 study 的活，也不构成「赢家」）**

5. **把 77% 的特质波动降下来 = 分散化。** §1 第 3 条显示系统性地板只有 **12.50%**，而闸门要求 vol ≤ **12.41%** —— 二者几乎相等 ⇒ **纯分散在数学上刚好够不着**（把特质压到 0 才勉强到地板）。所以可复用的问题不是「多持几只」，而是「**在保住 2023-H1 那种板块暴露的同时，能否把特质份额压到远低于 77%**」——那是一个新策略的设计问题，属 auto-enhance / research，不属本家族的解剖。⚠ 且必须带上 [[三进兵]] 的陷阱：**仓位是尺度旋钮，换不出夏普闸**。

**⚠ 现实性红线 —— 挂旗、不裁决（human decision）**

6. **缺失的「停牌 / 涨跌停」过滤（harness §3）。** 网格逻辑**每天对每只持仓票下单**，因此对不可成交日的敏感度**高于**低频策略：涨跌停日的委托在实盘会**不成交**，回测里却成交了。**方向未测**（补上过滤既可能提高也可能降低读数）。ST / 次新在市值前 30 的大盘股上基本是 moot，**但那两道闸不是**。**是否要求本家族的任何后代补上这两道过滤，交人工裁定。**
