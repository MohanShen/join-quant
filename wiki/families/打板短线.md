# 打板短线 — strategy family

**一句话**：昨日首板（涨停）个股，次日 09:26 集合竞价后按开盘价买入、当日 11:25 与 14:50 以「浮盈即止盈」或「跌破 MA5 止损」了结的 1–2 日隔夜接力；基类的特征是把**首板高开 / 首板低开 / 弱转强三个候选池混成一个等权组合**。

## 1. 基类 (base archetype)   ← study [[study-baseline]] / [[study-q-3]] 部分填写
- **Universe 选股池**（源码核对）：全 A（`get_all_securities`）→ `prepare_stock_list` 取昨日首板候选，再按三条腿各自过滤：前日成交额带（高开腿 5.5e8–20e8、弱转强腿 3e8–19e8）、总市值 ≥70 亿且流通市值 ≤520 亿、均价口径的收盘获利比例（高开腿 ≥7%、弱转强腿 ≥−4%）、竞价量/前日量 ≥3%、竞价比价带（高开 1.00–1.06、低开 0.955–0.97、弱转强 0.98–1.09 相对涨停基准）、「左压」条件（101 日高点以来成交量同步放大）。第 177 行 `qualified_stocks = sbgk_stocks + sbdk_stocks + rzq_stocks` 是三池的直接拼接，可用现金按当日候选数**等分**（第 46 行）。
- **交易频率**：日频、隔夜持有。**实测 `avg_position_days 1.51`**（2022 单年，study q-3 的 stats 回收数据）——源码隐含的 1–2 日持有被数据印证，不是叙事。换手 `turnover_rate 0.3061`。
- **交易机制**：入场 09:26 `order_value(s, value, MarketOrderStyle(current_data[s].day_open))`（第 50 行，显式请求按当日开盘价成交；⚠ 日线台是否采纳该价格参数**未测**，见 §4 q-1）；出场两次 `run_daily(sell)` 于 11:25 与 14:50——止盈（63–66 行：未封涨停且 `last_price > avg_cost` 即清仓）、止损（69–72 行：`last_price < MA5` 清仓）。**结构性观察（待 q-2 实测）**：止盈条件只在浮盈时触发，因此 **MA5 止损是唯一的亏损出口**。
- **基线绩效**（frozen harness, TRAIN 2022–2023）：见 §3；本轮独立复现该行**逐位相同**（obj 0.9668 / sharpe 2.58 / annual 129.24% / maxDD 32.56%），并补上 §3 没有的**两年总回报 +424.33%**（729 天）。**gate 余量仅 0.08**（sharpe 2.58 对 2.5）。
- **为什么有效**：目前**只知道「在哪一年有效」，尚不知道「哪个组件有效」**。(a) **年度分布已测**：整段 +424.33% 全部由 **2022 熊市年**产出（total +442.51%、sharpe 8.01、maxDD 25.10%），2023 算术反解约 **−3.35%**——合并头条描述的是一个不存在的年份（study q-3）。(b) **成交结构已测**：胜率 69.87%（109 胜 / 47 负）、盈亏比 2.28、日胜率 54.13%、平均持仓 1.51 天 —— 是一个**高胜率 × 正盈亏比**的短周期接力，收益并非来自少数暴利尾巴。(c) **待后续实验**：三池混合是否承重（q-4）、MA5 止损是否为唯一回撤压制器（q-2）、手调阈值的脆性（q-5）、以及最前置的成交语义（q-1）——在 q-1 落定前，本条所有绝对水平都只能读作「在某种未知成交语义下」。
- **⚠ 现实性 / 容量**：见 frontmatter `realism`。要点：零滑点 × 全库最高换手风格、一字封板常买不进（harness §3 红线）、日线台三个盘中时点塌缩为同一根 bar、收益单年集中。

### 4.2 执行/工具约束（影响本家族此后每一次实验）
- **本基类是 wall-clock 重量级**：单年跑只计费约 8 JQ 分钟，却**超过执行器默认的 20 分钟轮询上限**。此后每个实验都必须传 `--max-poll-min 35`（`strategy-post-backtest.js` 的普通 CLI 参数），否则会白烧配额并返回 `slow-skipped`。
- **疑似同因**：`harness/normalize-train.tsv` 中两个长期 `slow-skipped` 成员（`b8a7451f`、`914d5724`）很可能是同一原因，**或许可用同样方式回收**（待验证，只标不裁决）。
- **`slow-skipped` 的零成本回收路径（本轮首次用成）**：读该 algorithm 的 buildList 取 backtestId → `POST /algorithm/backtest/stats?backtestId=<id>&ajax=1`。凡 JQ 端状态为「完成」的跑都可回收，不额外计费。

### 4.3 stats-API 新开放的探针问题（此前被认为不可问）
执行器的 10 列 SUMMARY 丢弃了大量字段；stats 接口直接给出 `win_ratio / profit_loss_ratio / avg_position_days / turnover_rate / day_win_ratio / sortino / algorithm_volatility` 等，**部分解除了「本台无法做 probe 类问题」的限制**。由此新可问：
- 消融前后**胜率 vs 盈亏比**哪一侧被改动（区分「选股变准」与「拿住了大赢家」）；
- `avg_position_days` 是否随止损/止盈改动而变（验证退出规则是否真的在动作）；
- `turnover_rate` 的变化 → 与零滑点高估幅度直接挂钩，可给 realism 一个可比刻度。

### 4.4 数据完整性存疑（⚠ 只标记，不裁决）
- §3 第 3 行 [[01d39031_首板一进二V17代价敏感]] 的三元组**内部不自洽**：sharpe 13.66 / annual 9.19% / maxDD 38.37%。夏普 13.66 与 38% 回撤在数学上难以并存（同时 annual 仅 9.19% 却给出 obj −0.2918）。疑为归一化账本 artifact 或串行错位，**留待人工核对**，本轮不据此做任何推断。

### 4.5 本台不可回答
- 2025+ OOS 硬阻断；2024 / 2024-02 等 regime 本轮未覆盖。
- 真实成交约束（一字板买不进、竞价冲击、分钟频止损）须换 harness 纪元 → 属人类决策，跨纪元不可并列。

## 6. 研究问答 (study-log)

- **[基线锚点]** 冻结快照 `study/打板短线/baseline.py` 在 TRAIN 上的复现验证（type: baseline）
  **→** 逐位复现了 2026-07-27 的 §3 快照（obj 0.9668 / sharpe 2.58 / annual 129.24% / maxDD 32.56%）——那行历史读数可信、且与当前 harness 同一纪元；新信息是 §3 从未记录的**两年总回报 +424.33%**（729 天），以及**极薄的 gate 余量**（sharpe 2.58 对 2.5 只富余 0.08，任何消融都可能把家族头名打成 DQ）。（confidence high；⚠零滑点高估 / ⚠打板成交不真实 / thin-gate-margin）溯源 [[study-baseline]]

- **[Q q-3]** 把冻结基类原样跑 2022 单年，收益是否高度集中在 2023？2022 熊市里这套打板边缘还成立吗？（type: regime）
  **→ 假设被证伪，且方向完全反转**：2022 单年 total **+442.51%**、annual ≈ **445.0%**（harness §4 口径）、sharpe **8.01**、maxDD **25.10%**（回撤窗 2022-01-17→2022-02-18）。预注册的两条证伪项（2022 annual ≥100% **且** sharpe ≥2.5）**同时触发**。由此算术反解 2023：`total(2023) ≈ 5.2433/5.4251 − 1 ≈ **−3.35%**` → **TRAIN 的全部 +424.33% 都产自 2022 这个熊市年，2023 略负**；合并头条 annual 129.24% / sharpe 2.58 是「灿烂的 2022」与「平到略负的 2023」的平均，**描述的是一个从未发生过的年份**。（Δ 不适用——同一快照换窗口；confidence high；⚠零滑点高估 / ⚠打板成交不真实 / regime-specific / recovered-result）溯源 [[study-q-3]]
  - **口径纪律**：单年 sharpe 8.01 ≥ 2.5 虽形式上过闸，但 harness §4 的正式 objective 只定义在 TRAIN/VAL 上，故信息性 score `annual − maxDD = 4.199` **仅描述性，绝不与 TRAIN 的 0.9668 并列排名**。年化用 `(1+total)^(365/364)−1`；JQ 自带 `annual_algo_return 4.7370` 走 250 交易日口径，**不采用**（口径差异在此记录）。**只有总回报可跨子窗反解——sharpe 与 maxDD 不可分解，因此本页不给出 2023 的 sharpe/maxDD**。
  - **来源如实记录（非常规）**：执行器撞上自身 20 分钟轮询上限后 emit `slow-skipped` 且无法取消（JQ：在此状态不能取消），但 JQ 已计费 8 分钟、该跑在服务端**确已完成**（算法 `d8f2af399c0262cb883dddf6a5cff004`，buildList 行状态「完成」07分43秒），指标经 `POST /algorithm/backtest/stats?backtestId=<id>&ajax=1` 零额外成本回收。**本结果未走 harness §5 的 `SUMMARY status=completed` 正常契约**，但底层回测是真实完成的。
  - **附带机理数据**（SUMMARY 十列全部丢弃，来自同一 stats payload）：`win_ratio 69.87%`（109 胜 / 47 负）、`profit_loss_ratio 2.28`、**`avg_position_days 1.51`**、`turnover_rate 0.3061`、`day_win_ratio 54.13%`、`sortino 13.44`、`algorithm_volatility 0.586` —— 1.51 天**实测**印证源码隐含的 1–2 日持有。
