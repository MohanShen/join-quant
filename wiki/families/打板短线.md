# 打板短线 — strategy family

**一句话**：昨日首板（涨停）个股，次日买入、以「浮盈即止盈」或「跌破 MA5 止损」了结的 **1.51 天（实测）**隔夜接力；基类把**首板高开 / 首板低开 / 弱转强三个候选池混成一个等权组合**，而 q-4 实测三池极不等权：弱转强腿只占约 17% 成交笔数却承载约一半终值。**收益来源 = 涨停事件之后的延续（u-nolimit，epoch 6）**：候选表换成非涨停的强势票，同一台机器从 +442% 塌到 −10%。⚠ 全部业绩属于 2022 一年（q-3 / u-2023：2022 +442.51%，2023 −3.35%，四个半年单调衰减）。基类在 epoch 6 上 obj 0.9668 / sharpe 2.58（baseline-e6，过 1.5 闸）——但它在归一化账本里没有行（pending），所以 §3 把它列为 DQ/—。**VAL 2024–25 过闸**（年化 464% / sharpe 7.48 / maxDD 44%，[[study-val-base-e6]]），每年仍是「上半年肥尾、下半年退潮」；⚠ 原帖 2026 年发布，VAL 对作者是样本内，且零滑点 × 一字板可成交。⚠⚠ **本页 2026-09-22 前的 §3 前三名（obj 3.96 / 3.30 / 2.71）是仪器伪影**——执行器把作者头注释里的「策略收益2483.22%…最大回撤13.13%」读成了结果（[[study-e6-ledger-audit]]）；实测三行是 −0.15 / −0.03 / −0.15，家族在 epoch 6 上 **0 过闸**。

## 1. 基类 (base archetype)   ← [[study-baseline-e6]] 起溯源；epoch-2 的 baseline / q-3 / q-1 / q-2 / q-4 / q-5 见 §6
- **基类**：[[439385b4_首板高开低开弱转强混合]]（子匀，post/48680）。⚠ 账本在 **任何 epoch 都没有它的行**（它在 `data/pending-normalize.json` 里；2026-07 的 §3 行随账本回退丢失），2026-08 的 6 条 finding 全部量在 pin 之前的台上、且 q-1/q-2/q-4/q-5 只跑了 2022 子窗。epoch-6 快照 `study/打板短线/baseline-e6.py`（`build-e6.js` 生成；所有变体 = py2to3(源码) + 断言过的改动 + live OVERRIDE）。源码不调 set_slippage / set_commission / set_order_cost、已设 avoid_future_data，唯一可能绑定的 pin 是 `order_volume_ratio=0.05`。
- **Universe 选股池**（源码核对）：全 A（`get_all_securities`）去科创/北交/ST/停牌/次新 → `prepare_stock_list` 取**昨日首板**（`close==high_limit` 且前一日未涨停）与**昨日曾涨停未封板**两张表，再按三条腿各自过滤：前日成交额带（高开腿 5.5e8–20e8、弱转强腿 3e8–19e8）、总市值 ≥70 亿且流通市值 ≤520 亿、均价口径的收盘获利比例（高开腿 ≥7%、弱转强腿 ≥−4%）、竞价量/前日量 ≥3%、竞价比价带（高开 1.00–1.06、低开 0.955–0.97、弱转强相对涨停基准 0.98–1.09）、「左压」（101 日高点以来成交量同步放大）。第 177 行 `qualified_stocks = sbgk_stocks + sbdk_stocks + rzq_stocks` 直接拼接，可用现金按当日候选数**等分**（第 46 行）。
- **交易频率**：日频、隔夜持有；实测 `avg_position_days 1.51`、`turnover_rate 0.3061`（2022，q-3 的 stats 回收）。
- **交易机制**：入场 `order_value(s, value, MarketOrderStyle(current_data[s].day_open))`（09:26）；出场两次 `run_daily(sell)`（11:25 / 14:50）——止盈（未封涨停且 `last_price > avg_cost` 即清仓）、止损（`last_price < MA5` 清仓）。
  - **成交语义（q-1）**：去掉显式的 `MarketOrderStyle(day_open)` 后全部指标**逐位相同** ⇒ 策略无法影响自己的成交价，三个盘中时点在日线台上是同一根 bar。⚠ 这**不**等于成交价虚构：JQ 日线模式按当日开盘价成交，而 09:26 竞价价就是开盘价，所以「竞价选股 + 开盘价买入」在日线台上恰好是对的——虚构的是**能否买到**（一字板、5% 成交量上限之外的冲击），不是价位。**u-barprice（epoch 6）已钉死**：把价格参数改成 0.01 仍与锚点相同、笔数与持仓天数逐位相同——参数被丢弃，成交价是台子自己的规则（开盘价）；仓库级结论：日线台上任何 `MarketOrderStyle(price)` 都是装饰。
  - **MA5 止损 = 资金周转引擎（q-2）**：止盈只在浮盈时触发，止损一去亏损仓位没有出口——annual −200pp **且** maxDD +14pp，`avg_position_days 1.51→14.32`。它首先让资金 1.5 天翻一次去接新信号，其次才压回撤。
