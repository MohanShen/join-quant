# 给五福多ETF动量增加卖出冷却，7年54倍，最大回撤16%

五福 v7.2 + 卖出冷却机制 | 回测区间 2019-09-04 ~ 2026-09-04

## 一、先说结果

| 指标   | 数值                      |
| ---- | ----------------------- |
| 区间收益 | **5466.32%**            |
| 年化收益 | **80.72%**             |
| 最大回撤 | **16.37%**              |
| 回测区间 | 2019-09-04 ~ 2026-09-04 |

跑的是五福 多ETF 分散持仓 动量轮动，策略克隆自聚宽文章：https://www.joinquant.com/post/76568（作者：rbq2025）。在原策略基础上，经过多次回测研究：调整买卖时间、取消择时买入机制、单ETF持仓等，最终发现**加入了卖出冷却机制**，回测效果比预期好，单独开一帖聊聊这个机制。

## 二、痛点：止损在动量策略里是个"磨损源"

玩过动量轮动的朋友应该都见过这个场景：

```
某ETF触发止损，卖出
→ 第二天它score还是全场最高
→ 系统判定"最优标的"，买回
→ 第三天继续跌，再次止损
→ 循环往复，一次行情磨损掉好几个点
```

问题不在于止损本身——止损必须要有。问题在于**卖出的决策和买入的决策是两套独立逻辑**：卖出看的是风险（跌破止损线），买入看的是收益（动量得分）。一只刚被你止损掉的 ETF，动量分不会一夜之间消失，于是它第二天依然排在候选池前列。

止损卖得对不对？对。回买买得对不对？按打分逻辑也对。但两件"对"的事叠在一起，就是持续的摩擦成本。

## 三、解法：卖出冷却，简单粗暴但有效

机制一句话讲完：

&gt; **任意卖出成交后，该标的 2 个交易日内禁止再买回。**

具体规则：

- 卖出当日不买回（掐掉"当天止损当天回"）
- 卖出后再过 2 个交易日才解锁：周一卖出 → 周二、周三禁买，周四恢复
- 冷却对**所有卖出路径**生效：轮动换仓、分钟级止损、当日跌幅止损、防御切换，一视同仁

这个机制不是我原创的，是从另一个单持仓轮动策略（七星175）里借鉴来的。七星那边验证过它的价值，我把它移植到五福的多持仓框架里，效果同样成立。

## 四、实现要点（想移植到自己策略的朋友看这里）

关键就一条：**把冷却逻辑收口在统一下单函数里，而不是在每个卖出函数里各改各的。**

五福所有的交易都经过 `smart_order_target_value` 这一个下单入口（全文件唯一的 `order()` 调用点），所以只需要：

1. **买入方向**：下单前查 `is_in_sell_cooldown()`，冷却期内直接拒绝；
2. **卖出成交后**：调 `mark_sell_cooldown()` 记录卖出日期。

这样换仓、止损、防御切换全部自动覆盖，不需要碰任何策略逻辑。

交易日数用 `get_trade_days(start_date=卖出日, end_date=今天)` 计算，回测和模拟盘口径一致，跨月、跨节假日都不会算错。

核心代码就三个函数（完整代码见文末）：

```python
def mark_sell_cooldown(security, context):
    """卖出成交后记录日期"""
    g.last_sell_dates[security] = context.current_dt.date()

def trading_days_since_sell(security, context):
    """距卖出日过了几个交易日；0=卖出当日"""
    sell_date = g.last_sell_dates.get(security)
    if sell_date is None:
        return None
    return len(get_trade_days(start_date=sell_date,
                              end_date=context.current_dt.date())) - 1

def is_in_sell_cooldown(security, context):
    """是否处于冷却期：卖出当日+2个交易日内禁买"""
    days = trading_days_since_sell(security, context)
    if days is None:
        return False
    return days == 0 or days &lt; = g.sell_cooldown_days
```

参数只有一个：

```python
g.sell_cooldown_days = 2   # 冷却交易日数，可自行调整
```

## 五、为什么它有效（个人理解）

冷却本质上是给交易系统加了一个**"反悔期"**：

1. **止损后不接飞刀**：刚破位的标的往往有惯性下跌，2 天冷却让它把这一段跌完；
2. **过滤假信号回买**：如果一只 ETF 的动量是真的，2 天后它还在候选前排，你只是晚买 2 天，损失有限；如果 2 天后它掉出前排，说明之前的"高分"本来就是噪音——这笔回买本来就不该做；
3. **换手率实打实降下来**：磨损减少的同时，佣金和滑点成本也跟着降。

代价也是有的：如果策略卖错了（卖飞），冷却会延迟 1-2 天纠偏。牛市主升浪里偶尔会因此少赚一段。但从回测看，减少的磨损 &gt; 延迟的纠偏，净效果为正。

## 六、几点提醒

1. **冷却对部分减仓同样生效**：如果策略有调低仓位的操作，减仓后 2 日内也不能加回。五福是全卖全买的轮动模式，不受影响，但移植到有加减仓逻辑的策略时要注意这点；
2. **防御篮子交互**：刚被轮动卖出的 ETF，2 日内如果进入防御期且恰好在防御篮子里，当日买不进，仓位留现金。这是预期行为，不是 bug；
3. **冷却天数建议 2-3 天**：太短掐不住循环，太长会明显错过纠偏窗口，2 天是我在这个策略框架下试出来比较平衡的值，仅供参考；
4. 本帖机制分享为主，**不构成投资建议**，动量轮动本身波动不小，请对自己的风险承受能力有数。
