# 【文竹3.4更新】年化17.6%|最大回撤12.43%

###【2026年7月30日更新】文竹 v3.3 vs v3.4 — 差异对照！
---
#### 改动点 1：仓位2

**v3.3：** 仅首道防线
```python
if zf &gt; -6:
    g.stock_fund_2 = ETF_DIVIDEND   # 红利
else:
    g.stock_fund_2 = ETF_BOND      # 债券
```

**v3.4：** 加 MACD 月线确认
```python
if zf &gt; -6 and macd_div &gt; 0:         # ← 新增条件
    g.stock_fund_2 = ETF_DIVIDEND
else:
    g.stock_fund_2 = ETF_BOND
```

**效果：** 红利跌了但跌幅未到-6%时，MACD 月线转负会提前切债券，减少震荡市中红利下行的回撤。

---

### 改动点 2：仓位4

**v3.3：** 永远债券，动权重时不改标的
```python
g.stock_fund_4 = ETF_BOND           # 硬编码
```

**v3.4：** 分级选择标的
```python
if g.stock_fund_1 in (ETF_GROWTH, ETF_OVERSEAS):
    g.stock_fund_4 = ETF_DIVIDEND    # 牛市拿红利
else:
    g.stock_fund_4 = ETF_BOND        # 防御拿债券
```

**效果：** 牛市时 30% 仓位不再浪费在债券上，转持红利低波。与仓位2合并后红利总仓位可达 40-50%，弹性明显提升。

### 策略逻辑

**一句话：每月看一眼4个ETF的MACD月线，用简单的if/else决定买什么，固定权重，不做任何花哨操作。**

#### 资产配置

```
仓位1 (30%) → 创业板50 / 纳指 / 红利低波 / 30年国债
仓位2 (20%) → 红利低波 / 30年国债
仓位3 (20%) → 黄金 / 红利低波
仓位4 (30%) → 30年国债（固定）
```

#### 调仓规则

- **频率**：每月第1个交易日 9:35
- **年度清仓**：每年1月第1个交易日清仓所有（年度再平衡，避免跨年数据偏移）
- **合并**：同一标的在多个仓位出现时，权重自动合并，避免重复下单

### 核心优势

#### ① 少即是多——不加任何保护措施

v3.0最反直觉的地方：**故意不做止损、不做动量过滤、不做动态权重。**

历史教训：v1.0加了止损+动量过滤+动态权重，年化从15.73%干到5.56%。**每层"保护"在震荡市都是收益杀手。**

不加止损的逻辑：ETF轮动策略的信号是MACD月线，一个月才判断一次。如果在两次判断之间因为单日大跌触发了止损卖在最低点，等下次月线调仓时可能已经涨回去了。月频框架下止损不是保护，是反向操作。

#### ② MACD月线天然过滤噪音

日线MACD一天变一次，容易追涨杀跌。月线MACD一个月才变一次信号，用12/26/9的慢速参数，**只有真正的大趋势才会触发切换**。2020年3月创业板暴跌时月线MACD转负，4月反弹时转正——一轮完整的"卖出避险→抄底回来"只用了两个月。

#### ③ 仓位3的"Bug"策略

原版仓位3存在一个有趣的设计：黄金MACD≤0时**仍然默认持有黄金**，而不是切回债券。从纯技术角度看这是错误——信号已转空却不卖。但从组合角度看，黄金在回测期内整体趋势向上，持有黄金的时间越多收益越高。

这个"bug"实际是个隐含判断：**黄金的趋势性比债券强，宁可多扛一点波动也别频繁切来切去。**

#### ④ 四象限覆盖

不同经济环境下策略的自动映射：

### ⚠️ 局限性

1. **牛市跑输纯权益**：Beta只有0.372，2020年大牛市时仓位4的30%债券在拖后腿。但换来的好处是2022年熊市只跌了不到10%。

2. **月频调仓有滞后**：如果某个月中出现V型反转（比如突发利好月线大涨），策略要等到下个月才能补仓。这是月频框架的固有问题，但也是用滞后换稳定的代价。

3. **红利低波年收益-6%的阈值**：这个参数在回测期内工作良好，但如果市场结构发生永久性变化（比如红利因子永久失效），这条判断可能需要重新校准。

4. **回测期有限**：聚宽回测覆盖了2019-2026年的完整牛熊周期，但A股和ETF生态在快速变化，新策略上线后需要持续观察。
