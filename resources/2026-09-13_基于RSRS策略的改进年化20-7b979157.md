不过策略中的风险控制有点没看明白

```
# 计算均值序列    
    section = g.ans[-g.M:]
    # 计算均值序列
    mu = np.mean(section)
    # 计算标准化RSRS指标序列
    sigma = np.std(section)
    #  (最新的beta - 全部的平均值) / 标准偏差 
    zscore = (section[-1]-mu)/sigma
```
