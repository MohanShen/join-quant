眼尖的朋友会发现，聚宽下单详情与同花顺委托记录，数量和标的对不上。这不是下错单或漏洞，实质是因为跟单器开了「多策略仓位管理」——同花顺里的委托其实是两个策略一起跟单合起来的结果。

你可以在仓位管理里给每个策略单独调「买卖比例」。买卖的股数会按比例缩放。比如你信号是买 1000 股、比例设0.5，同花顺那边就跟 500 股；比例设1.0，就 1:1 全跟。

可用金额也按比例缩放。聚宽模拟盘的总资产，会按你这个策略的比例换算成同花顺这边的可用资金，下单时守住这个上限。

####小提醒：
资金管理需每日手动维护。本人手艺有限，这块没做自动化。

![Img](https://image.joinquant.com/3ac6fe7f27531e25e067d8113a5a7389) 

首页这版我也做了简化，把上一代的网页版跟单那些功能删掉了。跟单器想跑到"1 秒 1 单"的速度，需自行配置服务器及安装R.e.d.i.s信号对接。装完顺手把「买二卖二」勾上（这步能省 0.2~0.4 秒），同花顺设置也要勾选买二卖二。

##以下是基于 R.E.D.I.S 信号源的配置教程
####第一步：修改 R.E.D.I.S发射端《tools_ths.py》的配置
打开《tools_ths.py》，搜索以下，并填入你的资料(R.E.D.I.S去除标点)

R.E.D.I.S_HOST, R.E.D.I.S_PORT, R.E.D.I.S_PASSWORD = "填写你的R.E.D.I.S地址", 填写你的端口, ""

####第二步：将配置好的《tools_ths.py》添加到研究环境

###第三步：配置以下代码到你需要跟单的策略（回测策略有示范）

如需跟踪多个策略，请在不同策略的STRATEGY_NAME配置不同的命名。

import tools_ths # ← 引入模块，跟你研究环境里面的文件名保持一致

STRATEGY_NAME = "五福V7.8" # ← 策略名称要跟你接收端的策略名称保持一致，用于多策略

def initialize(context):
    tools_ths.setup(context, STRATEGY_NAME) # ← 第一行，在initialize函数里面加，照着写

def after_code_changed(context):
    tools_ths.refresh(context, STRATEGY_NAME)  # ← 第二行，在after_code_changed函数里面加，照着写

def before_trading_start(context):
    tools_ths.refresh(context, STRATEGY_NAME)  # ← 第三行，在before_trading_start函数里面加，照着写

def handle_data(context, data):
    tools_ths.check_and_fix(context)  # ← 第四行，在handle_data函数里面加，照着写

####第四步：打开《聚宽转同花顺跟单器.py》
填入第一步R.E.D.I.S的资料。随后便可以开启测试。功能较多，具体可参考内附的使用说明书。不懂的问 AI。
