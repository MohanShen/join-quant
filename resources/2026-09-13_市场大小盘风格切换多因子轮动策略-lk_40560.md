# 市场大小盘风格切换多因子轮动策略

一、策略核心思想
这是一个多因子复合型量化策略，核心思想是根据市场环境动态切换不同风格，主要包含三个维度：

大小盘风格择时 - 通过比较大盘股和小盘股的相对强弱，决定配置方向

外盘ETF择时 - 当大小盘都不具备明显优势时，配置外盘ETF

市场温度择时 - 根据市场位置调整白马股筛选标准
**2.1 时间调度体系（修改后）**
```
run_daily(prepare_stock_list, '9:05')           # 每日：更新持仓和涨停列表
run_monthly(singal, 1, '9:00')                   # 每月：生成大小盘择时信号
run_weekly(monthly_adjustment, 1, '10:30')       # 每周：执行调仓（买入）
run_weekly(clear, 1, '10:15')                     # 每周：卖出补跌仓位
run_daily(stop_loss_morning, '11:25')             # 每日：上午止损
run_daily(stop_loss_afternoon, '14:50')           # 每日：下午止损

```


**2.2 三大择时模块**
**A. 大小盘择时（singal函数）**
核心逻辑：比较沪深300前20大流通市值股和中小板前20小市值股的N日涨幅
```
# 计算逻辑简化
B_mean = 大盘股组合平均涨幅
S_mean = 小盘股组合平均涨幅

if B_mean &gt; S_mean and B_mean &gt; 0:
    if B_mean &gt; 5: signal = 'small'  # 大盘过热，切小盘
    else: signal = 'big'              # 大盘温和，配白马
elif B_mean &lt; S_mean and S_mean &gt; 0:
    signal = 'small'                   # 小盘强势，配小市值
else:
    signal = 'etf'                     # 都弱，配外盘ETF
```

**B. 市场温度择时（Market_temperature函数）**



cold	指数处于20%分位以下	PB&lt; 1, 经营现金流/利润&gt;2, ROE&gt;1.5%
warm	60日涨幅&gt;20%	PB&lt; 1, 现金流/利润&gt;1, ROE&gt;2%
hot	指数处于90%分位以上	PB&gt;3, 现金流/利润&gt;0.5, ROE&gt;3%

**2.3 三种选股模式**
模式1：白马股（big信号）
选股范围：沪深300成分股
过滤条件：

排除：ST、停牌、涨跌停开盘、创业板、科创、北交

根据市场温度动态调整财务门槛

排序逻辑：

冷/温：按(ROA/PB)降序

热：按ROA降序

模式2：小市值（small信号）
选股范围：中小板（399101.XSHE）

**2.4 风控体系**
A. 涨停打开卖出
```
# 对昨日涨停的股票，今日观察
if 当前价 &lt; 涨停价:
    卖出  # 涨停打开
else:
    持有  # 继续涨停
**
B. 止损机制**
硬止损：亏损超过8%时强制卖出

补跌机制：当日触发止损数量≥1时，用现金补仓跌幅最大的3只

**C. 涨跌停过滤**
买入时排除涨停/跌停股票

持有股票不受此限制（涨停可继续持有）
```
