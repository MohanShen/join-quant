# 五因子特征重要性加权综合得分选股

使用了 5个因子：pe_ratio, pb_ratio, roe, mom_20, vol_20
特征重要性排序为：mom_20 &gt; roe &gt; pe &gt; vol_20 &gt; pb
            # 权重归一化（越大表示越重要），注意方向：
            score = (
                (-pe) * 0.2 +      # PE 越低越好 → 取负
                (-pb) * 0.1 +      # PB 越低越好
                (roe) * 0.25 +     # ROE 越高越好
                (mom_20) * 0.3 +   # 动量最重要
                (-vol_20) * 0.15   # 波动越低越好
            )
每周调仓，调仓时间为每周一
