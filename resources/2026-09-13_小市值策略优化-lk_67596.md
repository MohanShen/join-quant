# 小市值策略优化

**在克隆的小市值基础上做了如下修改：**
**一、引入了基本面+技术面+动量三因子综合评分**
基本面因子：PE、PB、PS、ROE、净利润率、增长性等

技术面因子：均线系统、价格位置、成交量分析

动量因子：短期和中期动量指标

**二、强化风控**
```
# 新增止损止盈控制
g.stop_loss_rate = 0.08      # 8%止损
g.take_profit_rate = 0.25    # 25%止盈

# 仓位控制优化
g.max_position_ratio = 0.15  # 单股最大仓位15%
g.stock_num = 6              # 增加持股数量分散风险
```
实时风险监控

新增 check_risk_control() 函数监控单日亏损

增加 check_stop_loss() 和 check_take_profit() 个股风控
## 
**三、交易执行优化**
```
# 降低交易成本
OrderCost(open_commission=0.00025, close_commission=0.00025)  
vs
OrderCost(open_commission=0.0003, close_commission=0.0003)    

# 优化滑点设置
set_slippage(PriceRelatedSlippage(0.004))  
vs  
set_slippage(PriceRelatedSlippage(0.006))  
```
**四、数据处理完善**
**数据获取健壮性**

增加大量异常处理机制

修复字段名称错误（如inc_revenue_year_on_year）

**改进数据验证逻辑**

过滤条件精细化

新增 filter_recently_listed() 过滤新股

**改进ST股过滤逻辑**

增加流动性过滤（成交额&gt;1000万）

**五、运行频率优化**
```
# 附件1优化后的运行安排
run_daily(get_stock_list, time='9:15')
run_daily(check_risk_control, time='14:30')    # 新增风险检查
run_daily(check_limit_up, time='14:45') 
run_monthly(month_filter_stock, 3, time='10:30')  # 调整到第3个交易日
run_daily(after_trading_end, time='15:10')    # 新增收盘处理
```
积分有限，所以回测时间比较短，只有一年时间，有感兴趣的朋友可以自行延长回测时间。
