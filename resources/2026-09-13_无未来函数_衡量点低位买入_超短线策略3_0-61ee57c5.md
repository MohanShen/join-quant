# 无未来函数 衡量点低位买入 超短线策略3.0

优化点：
  1. 批量取数，大幅减少 API 调用次数（性能提升 &gt;80%）
  2. 增加大盘环境过滤，熊市自动降低仓位
  3. ATR 动态止损替代固定-2%止损
  4. VWAP 均价过滤，避免追高抄底
  5. 板块分散度检查，避免同板块过度集中
  6. 每日开仓上限 + 单日亏损熔断
  7. 更稳健的企稳判断（加入成交量萎缩确认）
  8. 时间窗口过滤（早盘不抄底、尾盘不开仓）
  9. 完善异常处理和日志
