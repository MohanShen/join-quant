#### **存取数据**
- [API原文 read_file](https://www.joinquant.com/api#readfile)
- [API原文 write_file](https://www.joinquant.com/api#writefile)
- **策略和研究中都能用。**
- **文件内容只能是 str或者unicode。**
- List与Dict等常规非字符数据,写入需`json.dumps()`，读取需`json.loads()`，所以需导入相应模块`import json`。
- DataFrame类型数据 写入需`.to_csv`，读取需`pd.read_csv`，`StringIO`。所以需导入相应模块`import pandas as pd`,`from six import StringIO`
- DataFrame类型数据在研究中有更简单的写法，不用`read_file`和`write_file`即直接`.to_csv`和`pd.read_csv`，但不能在策略中用，具体说明待更新。
